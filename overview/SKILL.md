# 考点总览类文档治理规范

> **适用范围**：`overview/` 目录下符合第一节判定条件的考点总览类文档（不枚举具体文件，见类属管辖原则）。
> **权威性**：本文件是本类文档新建、修订、校对和扩展任务的唯一权威规范。执行相关任务必须先遵循本技能。
> **职责边界**：本技能只管 `overview/` 目录内考点总览类文档的治理，对本目录内文档自洽自立。文档**允许且仅允许**向**上游依赖**作轻引用：其一为 `notes/` 目录下的上游文档，其二为直接由 `notes/系统分析师考试论文写作.md` 派生的 `essay/SKILL.md`；除此以外的目录外文档一律不得引用。上游依赖的变更不引起本规范的维护动作，仅在引用失效时按第二节第4项核对。

## 一、文档类别判定与管辖

**类属管辖原则**：本规范以**文档类别**而非文件清单划定管辖——只要满足下列判定条件即自动纳入管辖，无须另行登记；本规范因此不维护文档清单，新增同类文档不引起本规范改动。

判定为「考点总览类文档」须同时满足：

1. **收录对象是考点**：以知识点／题型为最小条目单元，不逐字照搬教材原文，不收录试题原文。
2. **组织方式是聚合视图**：跨越教材章节或科目边界重排知识点，而非按教材目录顺序平铺。
3. **文档目的是上游考情参照**：对考点作出收录判定与权重分级，供下游编制环节引用，允许并预期按考情复核更新（区别于只做版式维护的固化文档）。

不符合上述三项的文档（按教材目录平铺、忠实官方原文、面向单科应试技能等）不属于本类，不适用本规范。

**组织轴**：同类文档内部按组织轴区分，组织轴决定版式（见第二节）：

- **章节轴**：按 2024版考纲科目一条目顺序**映射**《系统分析师教程（第2版）》对应章节，逐条梳理知识点框架（考纲条目与教材章节非严格一一对应，存在跨章、共章及无独立章节（归口）等情形；文档须在头部「文档定位」中声明所依从的序列及映射关系）；
- **科目轴**：按科目／题型的轮换关系聚合命题方向（如案例分析必答与选答方向的轮换、论文主题的交替），不逐考点作分级，故用编号列表而非分级表格。

> 同一目录内可并存多条组织轴；组织轴是文档属性，不由文件数量或文件名决定。

**优先级不单独成轴**：考频／优先级**不作为独立组织轴**。凡需对章节作优先级分级者，一律以「**复习优先级速览**」（判定标准表，见第二节第5项）承载；正文的数据表统一以**教材章节为主键**，**不得另立按梯队重排的数据表**（避免同一批考情数据出现两个出处、日后相互漂移）。

**内容权威来源（固定三源）**：2024版考纲 ＋ 《系统分析师教程（第2版）》 ＋ 2021年以后系统分析师真题考情。三源不因文档而异，不得以外部资料替代。

**文件名为固定标识符**：文内交叉引用只写文件名、不写路径，改名会破坏引用链，原则上禁止改名。

## 二、公共治理要素（强制）

**版式不跨文档强求统一**：版式由组织轴决定——章节轴文档在标题直写十进制层级序号（`## N`、`### N.M`）＋`[TOC]`；科目轴文档用编号列表（`## N` 小节＋有序列表）＋`[TOC]`。强行统一版式会迫使组织轴扭曲，故本节只约束与组织轴无关的以下公共要素：

1. **头部元信息块**：标题之后、正文之前，用引用块逐条列出。**必备四项**——适用科目、教材基准（《系统分析师教程（第2版）》）、考情口径、文档定位（组织轴说明＋与其它同类文档的分工）；**按轴可选行白名单**——量度、版本说明、说明（择需增补；同组织轴的文档间同类可选行须对齐，不得一份有一份无；白名单外不得新增行）。新增文档须在「文档定位」中显式声明自身组织轴与分工。
2. **考情口径**：全文考频表述（高频／中频／低频／历年／稳定出题等）一律以**2021年以后系统分析师真题**为统计口径，在头部「考情口径」行统一声明，不必逐行标注；**弃用分值**，如确需出现分值类表述，须保留「非官方统计、实际浮动」声明。量度词表与优先级表述见第6项。
3. **编号引用规则**：条目级引用写「考纲第N条」、子项级「考纲N.M」；行文章号不零填充（写「第2章」）；编号引用后禁拼量词（以「的」或标点分隔）；区间一律用全角「～」。
4. **名称与引用一致性**：考纲条目名以 2024版考纲原文为准，教材章名以《系统分析师教程（第2版）》目录为准，不得出现名称漂移或自造简称；文内交叉引用提及的文档、章节、区块须真实存在，不得指向不存在的名称或形态。**上游依赖引用写法**：`notes/` 上游文档以《文件名（不含扩展名）》书名号形式引用；`essay/SKILL.md` 以固定的 `essay/SKILL.md` 形式引用（因与本目录 `SKILL.md` 同名，须以目录限定消歧）。
5. **正文段落骨架**：正文按组织轴配置小节，同类小节须同名、同写法、同位置。
   - **公共必备收尾小节「章节维度考情总览」**——以《系统分析师教程（第2版）》章节为维度回看本文件口径，**所有文档一律以该表承载**（以教材章节为首列／主键，该列取名为「教材章节」），置于正文末位。
   - **复习优先级速览**（判定标准表：`梯队｜判定标准｜落入章节`）——凡对章节作出优先级分级（第一梯队／第二梯队／第三梯队）的文档，**皆须以本小节承载分级依据**，并置于「章节维度考情总览」之前；「章节维度考情总览」另设**「复习梯队」列**（取值＝第一梯队／第二梯队／第三梯队），与该速览**同源同判**。除此之外，正文不得再出现第三张按梯队重排的表格。
   - **科目轴专属**：**口径与边界**（置于「章节维度考情总览」之前）。
   - **计算题类文档专属**（收录对象限于可数值计算考点者）：**无计算题章节**（仅概念／识图／简答的反向清单）＋**备考提示**，置于「章节维度考情总览」之后。
   - 小节标题一律语义完整，禁用口语化简称与变更记录式表述。
6. **术语与量度一致性**：量度词按科目分用——综合知识用「题量（道）／频次（次）」，案例分析用「题组」，论文用「题次」，跨科文档按科分别使用，弃用「分值」；**优先级一律用「第一梯队／第二梯队／第三梯队」三档表述，不得另立他名或采用图形标识**。
7. **字符混排空格**：依据 CY/T 154—2017《中文出版物夹用英文的编辑规范》第8章（该标准规范性引用 GB/T 15834—2011《标点符号用法》、GB/T 15835—2011《出版物上数字用法》，并指向 GB 3101—1993《有关量、单位和符号的一般原则》），本目录按以下规则处理混排空格：
   - **汉字与西文单词、字母之间留一个半角空格**（U+0020）。依据 §8.1：留与不留由排版效果决定，但**「如留空格，应保证体例的统一」**——本目录体例**选定为「留空格」**，凡汉字与西文相接处一律执行，**全目录含标题在内不得出现此处加、彼处不加的混合写法**。
   - **西文与被相邻中文标点之间不留空格**（§8.2，强制性条款）。全角运算符号（如 ＋、－、＝）不属于中文标点，不在此列。
   - **数值与计量单位符号之间留空隙**（§12.2.2；GB 3101—1993 §3.4），如长度写作「3.4 mm」。
   - **不受本项规则约束、须保持原样的四类**（标准未作规定，按本目录体例免于调整）：① Markdown 结构符与列举标号后的空格；② 编号、序号与标题之间的空格（如「第16章 Web 应用系统分析与设计」「9.7.2 系统可靠性指标」）；③ 阿拉伯数字与中文计数单位的连写（如「8道/5场」「13题组」）；④ 数学公式区、行内代码、URL 与文件路径的内部写法。

## 三、编制后自检

- [ ] 类别判定：目标文档满足第一节三项条件；新增文档已声明组织轴，章节轴文档已在「文档定位」中声明所依从的序列及映射关系。
- [ ] 头部必备四要素齐全，同组织轴的同类可选行已对齐，未出现白名单外的行。
- [ ] 全文无缺口径的考频断言（「历年」「高频」等均在头部口径覆盖之下）。
- [ ] 编号引用合规（考纲第N条／章号不零填充／编号后不拼量词／全角～）。
- [ ] 考纲条目名、教材章名与官方原文逐一比对无漂移、无自造简称。
- [ ] 交叉引用提及的文档、章节、区块实际存在；上游依赖引用写法合规（`notes/` 用《文件名》，`essay/SKILL.md` 用目录限定）；未引用白名单以外的目录外文档。
- [ ] 正文段落骨架齐备：公共必备「章节维度考情总览」＋本轴专属小节（及计算题类文档的两项专属小节），标题同名、同写法、同位置。
- [ ] 全库唯一数据表：「章节维度考情总览」为唯一的章节级数据表，未出现第三张按梯队重排的数据表；优先级仅由「复习优先级速览」（判定标准＋落入章节）与总览表「复习梯队」列承载，且两处同源同判。
- [ ] 术语与量度一致：量度词按科目分用，优先级一律「第一梯队／第二梯队／第三梯队」，无图形标识与别名。
- [ ] 混排空格合规（CY/T 154—2017）：汉字与西文、字母相接处一律留一个半角空格，全目录体例统一；西文与被相邻中文标点之间无空格；数值与计量单位符号之间留空隙；数学公式区、行内代码、URL 与文件路径未被空格调整改动。
- [ ] 格式体检通过：标题前后空行齐备、无行尾空白、无连续空行、无半角「~」区间、表格无空行截断。
- [ ] 改动范围不超出 `overview/` 目录。
