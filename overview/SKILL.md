# 考点总览类文档治理规范

> **适用范围**：`overview/` 目录下符合第一节判定条件的考点总览类文档（不枚举具体文件，见类属管辖原则）。
> **权威性**：本文件是本类文档新建、修订、校对和扩展任务的唯一权威规范。执行相关任务必须先遵循本技能。
> **职责边界**：本技能只管 `overview/` 目录内考点总览类文档的治理。本规范自洽自立，不规定、不依赖、不引用本目录以外的任何文档及其组织结构；目录外的任何变更均不引起本规范的维护动作。

## 一、文档类别判定与管辖

**类属管辖原则**：本规范以**文档类别**而非文件清单划定管辖——只要满足下列判定条件即自动纳入管辖，无须另行登记；本规范因此不维护文档清单，新增同类文档不引起本规范改动。

判定为「考点总览类文档」须同时满足：

1. **收录对象是考点**：以知识点／题型为最小条目单元，不逐字照搬教材原文，不收录试题原文。
2. **组织方式是聚合视图**：跨越教材章节或科目边界重排知识点，而非按教材目录顺序平铺。
3. **文档目的是上游考情参照**：对考点作出收录判定与权重分级，供下游编制环节引用，允许并预期按考情复核更新（区别于只做版式维护的固化文档）。

不符合上述三项的文档（按教材目录平铺、忠实官方原文、面向单科应试技能等）不属于本类，不适用本规范。

**组织轴**：同类文档内部按组织轴区分，组织轴决定版式（见第二节）：

- **章节轴**：按考纲条目顺序逐条梳理知识点框架；
- **考频轴**：按考频分级聚合同一考点的全部出题形式；
- **科目轴**：按科目／题型的轮换关系聚合命题方向（如案例分析必答与选答方向的轮换、论文主题的交替），不逐考点作分级，故用编号列表而非分级表格。

> 同一目录内可并存多条组织轴；组织轴是文档属性，不由文件数量或文件名决定。

**内容权威来源（固定三源）**：2024版考纲 ＋ 《系统分析师教程（第2版）》 ＋ 2021年以后系统分析师真题考情。三源不因文档而异，不得以外部资料替代。

**文件名为固定标识符**：文内交叉引用只写文件名、不写路径，改名会破坏引用链，原则上禁止改名。

## 二、四项公共治理要素（强制）

**版式不跨文档强求统一**：版式由组织轴决定——章节轴文档在标题直写十进制层级序号（`## N`、`### N.M`）＋`[TOC]`；考频轴文档用分级表格；科目轴文档用编号列表（`##` 小节＋有序列表）。强行统一版式会迫使组织轴扭曲，故本节只约束与组织轴无关的以下公共要素：

1. **头部元信息块**：标题之后、正文之前，用引用块逐条列出，**至少包含四项**——适用科目、教材基准（《系统分析师教程（第2版）》）、考情口径、文档定位（组织轴说明＋与其它同类文档的分工）；可按需增补标识、说明等行，但不得缺项。**同组织轴的文档间头部要素须对齐，不得一份有一份无**；新增文档须在「文档定位」中显式声明自身组织轴与分工。
2. **考情口径**：全文考频表述（高频／中频／低频／历年／稳定出题等）一律以**2021年以后系统分析师真题**为统计口径，在头部「考情口径」行统一声明，不必逐行标注；分值类表述须保留「非官方统计、实际浮动」声明。
3. **编号引用规则**：条目级引用写「考纲第N条」、子项级「考纲N.M」；行文章号不零填充（写「第2章」）；编号引用后禁拼量词（以「的」或标点分隔）；区间一律用全角「～」。
4. **名称与引用一致性**：考纲条目名以2024版考纲原文为准，教材章名以《系统分析师教程（第2版）》目录为准，不得出现名称漂移或自造简称；文内交叉引用提及的文档、章节、区块须真实存在，不得指向不存在的名称或形态。

## 三、编制后自检

- [ ] 类别判定：目标文档满足第一节三项条件；新增文档已声明组织轴。
- [ ] 头部四要素齐全，且与同组织轴的其它文档对齐。
- [ ] 全文无缺口径的考频断言（「历年」「高频」等均在头部口径覆盖之下）。
- [ ] 编号引用合规（考纲第N条／章号不零填充／编号后不拼量词／全角～）。
- [ ] 考纲条目名、教材章名与官方原文逐一比对无漂移、无自造简称。
- [ ] 交叉引用提及的文档、章节、区块实际存在。
- [ ] 格式体检通过：标题前后空行齐备、无行尾空白、无连续空行、无半角「~」区间。
- [ ] 改动范围不超出 `overview/` 目录。
