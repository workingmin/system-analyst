### 1.1 核心知识点精讲

#### 1.1.1 基础概率定义（教材2.1.1）【教材｜了解】

1. 样本空间：所有可能结果集合；随机事件是样本空间子集。
2. 概率公理：$0 \le P(A) \le 1$；必然事件概率$P(\Omega) = 1$，不可能事件$P(\varnothing) = 0$。
3. 事件关系
  - **互斥事件（互不相容）**：集合层面定义$A \cap B = \varnothing$，即事件$A, B$不能同时发生；$A \cap B = \varnothing \implies P(A \cap B) = 0$，进一步得$A \cap B = \varnothing \implies P(A \cup B) = P(A) + P(B)$。
  > 注意：$P(A \cap B) = 0$无法反向推出集合互斥，连续随机变量存在非空但概率等于0的事件。
  - **对立事件**：$\bar{A}$代表事件$A$不发生；满足$A \cap \bar{A} = \varnothing, A \cup \bar{A} = \Omega$，有$P(\bar{A}) = 1 - P(A)$。
  - **独立事件**：事件$A$发生与否不改变事件$B$发生的可能性；定义式：$P(A \cap B) = P(A)P(B)$。

#### 1.1.2 条件概率、全概率与贝叶斯公式（教材2.1.1）【教材｜了解】

**条件概率定义**：在事件$A$已经发生的前提下，事件$B$发生的概率，记作$P(B|A)$，要求$P(A) > 0$。
$$P(B|A) = \dfrac{P(A \cap B)}{P(A)}$$

**全概率公式**：若$A_1, A_2, \dots, A_n$是样本空间$\Omega$的一个划分，则
$$P(B) = \sum_{i=1}^{n} P(A_i)P(B|A_i)$$

**贝叶斯公式**：由条件概率、全概率公式推导而来，用于已知先验概率，反向求解后验概率，其中$P(B) > 0$。
$$P(A_j|B) = \dfrac{P(B|A_j)P(A_j)}{\displaystyle\sum_{i=1}^{n} P(A_i)P(B|A_i)}$$
$$P(A|B) = \dfrac{P(B|A)P(A)}{P(B)}$$

> 记忆：已知先验概率，反向求后验概率；近年频次窗内该考点检出1道（2024下，由次品率反推产自哪台机器）。
> 例题1即标准「全概率＋贝叶斯」套路：先全概率求$P$（告警触发），再贝叶斯求$P$（故障|告警）。

#### 1.1.3 期望、方差（离散随机变量）（教材2.1.3）【教材｜了解】

**期望（数学期望/均值）定义**：设离散型随机变量$X$的所有可能取值为$x_i$，对应取值概率为$P(X = x_i)$，则$X$的数学期望为：
$$E(X) = \sum_i x_i P(X = x_i)$$
随机变量**长期大量重复试验下取值的加权平均值**，权重为各取值发生概率，反映随机变量取值的中心位置。

**方差定义**：
定义离差$\delta(X) = X - E(X)$；**离差的平方**：
$$\delta^2(X) = \big(X - E(X)\big)^2$$
含义：随机变量$X$的取值与其期望之差的平方。
离散随机变量$X$的方差，是随机变量与其期望之差平方的期望，即离差的平方$\delta^2(X)$的期望：
$$D(X) = E\big(\delta^2(X)\big) = E\big((X - E(X))^2\big)$$

离散随机变量方差展开形式：
$$D(X) = \sum_i \big(x_i - E(X)\big)^2 P(X = x_i)$$
刻画随机变量取值相对于期望的**离散/波动程度**；方差越大，取值越分散、不确定性越强；方差越小，取值越集中在期望附近。

性质：
- $E(aX + b) = aE(X) + b$（期望线性性质，$a, b$为常数）
- $D(aX + b) = a^2D(X)$（常数$b$不改变波动，仅缩放系数$a$平方影响方差）

#### 1.1.4 常用概率分布（教材2.1.4）【教材｜了解】

| 分布 | 适用场景 | 期望 | 方差 |
|---|---|---|---|
| 0-1分布（伯努利） | 单次试验只有两个结果 | $p$ | $p(1 - p)$ |
| 二项分布 $B(n, p)$ | n次独立重复试验中事件发生次数 | $np$ | $np(1 - p)$ |
| 几何分布 $G(p)$ | 首次成功所需试验次数 | $1/p$ | $(1 - p)/p^2$ |
| 泊松分布 $P(\lambda)$ | 稀有事件出现次数（误码数、不合格品数） | $\lambda$ | $\lambda$（期望=方差是其识别特征） |
| 均匀分布 $U(a, b)$ | 区间$[a, b]$上等可能 | $(a + b)/2$ | $(b - a)^2/12$ |
| 正态分布 $N(\mu, \sigma^2)$ | 大量独立小因素综合作用（误差、质量、进度） | $\mu$ | $\sigma^2$ |

> 记忆：泊松分布满足$E(X) = D(X) = \lambda$，可据此识别；二项分布$n = 1$时退化为0-1分布。伯努利二项概率公式$P_n(k) = C_n^k p^k(1 - p)^{n - k}$是二项分布基础。

#### 拓展·统计推断基础（教材2.1.5）【教材｜非必学】

- **总体/样本/统计量**：总体＝研究对象全部观测；样本＝抽出的子集；统计量＝不含未知参数的样本函数。常用统计量：样本均值、样本方差/标准差、样本$k$阶原点矩/中心矩、次序统计量。
- **参数估计**
  - 点估计：用一个数估计参数。常用**矩估计法**（用样本矩估计总体矩）与**极大似然估计法**（最重要）。
  - 区间估计：用区间$(a, b)$以给定**置信度（置信水平）**覆盖待估参数；区间越大置信水平越高，两端称置信下限/上限。
- **假设检验（显著性检验）**：依据样本判断总体指标是否等于某值、是否服从某分布；常用$U$检验、$t$检验、$\chi^2$检验、$F$检验。
- **回归分析**：研究变量间相关关系。分一元/多元、线性/非线性回归；参数估计常用**最小二乘法**；变量筛选用逐步回归、向前/向后回归。
- **方差分析**：把总变差按来源分解，判断可控因素影响是否显著。适用条件：**可比性、正态性、方差齐性**。分**单因素方差分析**与**双因素方差分析**（无交互/有交互）。
- **正交试验法**：用正交表做多因素试验设计，实现“**均衡分散、整齐可比**”，用少数试验找较优条件。

> 注：一元线性回归（最小二乘法）见模块1的核心知识点1.1.5（回归分析·一元线性回归）；此处统计推断其余内容一般只考概念辨析，不考公式推导。

### 2.1 核心知识点精讲

【前置基础｜教材无原文】下面为理解图论算法（最小生成树、最短路径、网络流）所需的基础语义；第2版教材2.2未单独展开定义，为离散数学通用概念。无向边清单中的$AB(3)$表示端点为$A, B$且权重为$3$的边；有向边清单中的$S \to A(3)$表示从$S$到$A$、权重为$3$的弧。
- 图$G = (V, E)$，$V$为顶点集合（非空），$E$为边集合（可为空）。
- 顶点集合成员写作$v \in V$；无向边以无序对$\{u, v\}$表示，有向边以有序对$(u, v)$或箭头$u \to v$表示。
- 无向图：边无方向。
- 有向图：边为带方向的弧。
- 简单图：无自环、无重复边。
- 完全无向图：任意两点之间存在边。
- $n$顶点完全无向图边数：$C(n, 2) = \dfrac{n(n - 1)}{2}$；（有向完全图弧数：$n(n - 1)$）。

#### 2.1.1 树与最小生成树（计算）（教材2.2.1）【教材｜掌握】

树：连通、无环的无向图。$n$个顶点的树一定有$n - 1$条边。

最小生成树MST（Minimum Spanning Tree）：连通全部顶点，总边权之和最小，且无环。
- Kruskal（克鲁斯卡尔）：将边按权值从小到大排序，依次选取边；不构成环则保留，构成环则丢弃，直至选中$n - 1$条边。适合稀疏图。
- Prim（普里姆）：任选一个起点，每次选择一端在已选顶点集合、另一端在集合之外的权重最小边，逐步扩张生成树。适合稠密图。

> 性质：最小生成树的总权重唯一，但树的拓扑结构不一定唯一。若图中所有边的权重互不相同，则最小生成树拓扑唯一。

#### 2.1.2 最短路径（教材2.2.2）【教材｜掌握】

- Dijkstra（迪杰斯特拉）：单源最短路径（一个起点到所有其他顶点）；仅支持边权不为负数，属本章中频核心考点。
- Floyd（弗洛伊德）：多源最短路径，一次性得到任意两点之间的最短距离；允许负权边，但图中不能存在负环；算法开销高，系统分析师一般只考察概念。

#### 2.1.3 网络与最大流量（教材2.2.3）【教材｜掌握】

1. 流网络（容量网络）：网络流理论的研究对象，为一类特殊的赋权有向图；指定源点$S$（只流出）、汇点$T$（只流入），边的权值代表容量。
2. 流量约束：$0 \le f \le c$；中间节点流入总量等于流出总量（流量守恒）。
3. 路径叠加法（教材2.2.3给出的手算方法）：从源到汇找可通路径，该路径流量等于该路径上各段剩余容量的最小值；算出后把各段容量扣减，容量归0的边断开；反复直到无路可通，累加各路径流量即为最大流。

> 约束：每条边满足$0 \le f \le c$；中间节点净流量为$0$（只起转运）；总最大流量唯一，但运输方案可不唯一。

#### 2.1.4 典型易错点（图论）

1. Dijkstra不能处理负权边，题目出现负权不可使用Dijkstra。【🟡中频】
2. 最小生成树只保证连通所有顶点，不保证原图任意两点是最短路径。【🟡中频】
3. 最大流的值不等于所有边容量之和；每条可通路径的流量受该路径瓶颈边限制（与最小割容量的关系见本模块拓展阅读）。【🟡中频】

**例题1【最小生成树 Kruskal】**

顶点：$A, B, C, D$
边：$AB(1), AC(4), BC(2), BD(5), CD(1)$
求最小生成树总权重。

```viz {engine="dot"}
graph G {

  A -- C [label="4"];
  B -- C [label="2"];

}
```

> 【解析】
> 1. 边从小到大排序：$AB(1), CD(1), BC(2), AC(4), BD(5)$
> 2. 依次选取：
>    - $AB = 1$，无环，保留；已选边$\{AB\}$
>    - $CD = 1$，无环，保留；已选边$\{AB, CD\}$
>    - $BC = 2$，无环，保留；已选边$\{AB, CD, BC\}$，4个顶点需要3条边，停止。
> 3. 总权重$1 + 1 + 2 = 4$
> 【答案】最小生成树总权重为4

**例题2【Dijkstra单源最短路径】**

顶点：$S, A, B, C$
边：$S \to A(3), S \to B(6), A \to B(2), A \to C(5), B \to C(1)$
求$S$到$C$最短距离。

```viz {engine="dot"}
digraph G {
  rankdir=LR;
  node [shape=circle];
  splines=curved;
  S -> A [label="3"];
  S -> B [label="6"];
  A -> B [label="2"];
  A -> C [label="5"];
  B -> C [label="1"];
}
```

> 【解析】
> 1. 起点$S$距离：$S = 0; A = 3; B = \infty; C = \infty$
> 2. 最近未访问点$A$（距离3）：
>    - 更新$B$：$\min(6, 3 + 2) = 5$
>    - 更新$C$：$\min(\infty, 3 + 5) = 8$
> 3. 最近未访问点$B$（距离5）：
>    - 更新$C$：$\min(8, 5 + 1) = 6$
> 4. 最近未访问点$C$（距离6）。
> $S$到$C$最短路径：$S \to A \to B \to C$，总长度6。
> 【答案】6

#### 拓展·更多最小生成树算法：Boruvka、反向删除（教材2.2.1）【教材｜非必学】

- **博鲁夫卡（Boruvka）算法**：不断为每个连通分量找连出的最小边加入，直至全连通；并行能力强、适合大规模图，复杂度约$O(E \cdot \log V)$。
- **反向删除（Reverse‑Delete）算法**：按边权**从大到小**依次删边，删除后图若不连通则保留该边；实现简单，稠密图效果较差，复杂度$O(E \cdot \log E)$。

> Prim适合稠密图（$O(V^2)$）、Kruskal适合稀疏图（$O(E \cdot \log E)$）的适用场景须记住；Boruvka/反向删除了解概念即可。

#### 拓展·更多最短路径算法：Bellman‑Ford、A*、Johnson、SPFA（教材2.2.2）【教材｜非必学】

| 算法 | 特点 | 能否处理负权 |
|---|---|---|
| Dijkstra | 单源，按路径长度递增，贪心 | 否 |
| Floyd | 多源（任意两点间），动态规划枚举中间点 | 能（不能有负权回路） |
| Bellman‑Ford | 单源，$n - 1$轮松弛，可检测负权回路 | 能 |
| A* | 启发式搜索，启发函数+已知距离指导 | 与启发函数相关 |
| Johnson | 全源，Bellman‑Ford转非负边+各源Dijkstra | 能 |
| SPFA | Bellman‑Ford的队列改进 | 能 |

> 近年考题集中在Dijkstra（不能负权）与Floyd（多源）概念上；其余算法教材有原文，但近年频次窗内未检出，了解算法定位即可。

#### 拓展·最大流最小割定理【真题补充｜考频｜两版教材均无原文】

> 收录依据：2021年以后真题反复外延命题（2024上、2025下均检出最大流量类选择题），两版教材2.2.3均无该定理原文（教材明确「本节不介绍有关网络与最大流量的理论知识」）。

1. 割：将顶点拆分为两组，$S$属于集合$A$，$T$属于集合$B$；割容量为所有$A \to B$方向边的容量之和，$B \to A$反向边不计入、不扣减。
2. 最大流最小割定理：$S \to T$的最大流值等于$S \to T$的最小割容量。

> 用法：用于确定最大流的上界、验算最大流结果；真题若问「最大流的上界由何决定」，即指最小割容量。

### 3.1 核心知识点精讲

#### 3.1.1 预测的基本内涵（教材2.3.1）【教材｜了解】

- 三条预测途径：**因果分析**（研究原因推未来）、**类比分析**（与历史「先导事件」类比）、**统计分析**（分析历史数据揭示规律）。
- 教材借助系统$S$、模型$M$、结论$C$三者相交得到7个区域，对应预测的7类情形；仅$S \cap M \cap C$（正确系统认知+正确模型+正确结论）为科学有效的预测，其余6类均存在信息失真，例如模型错误却碰巧得到正确结论。
- 预测目的：服务于决策（战略计划、流程优化、风险评估等）。

> 常考：正确预测＝系统、模型、结论三者吻合；错误建模却碰巧得到正确结论仍属失真。

#### 3.1.2 预测的程序（教材2.3.2）【教材｜了解】

1. 明确预测任务、制订预测计划；
2. 搜集、审核和整理资料（筛选标准：直接相关性、可靠性、最新性）；
3. 选择预测方法、建立数学模型；
4. 检验模型（理论上合理、统计可靠、预测能力强、简单适用）；
5. 分析预测误差、评价预测结果；
6. 向决策者提交预测报告。

> 记忆：任务计划→资料→方法模型→检验→误差评价→提交报告。

#### 3.1.3 预测的方法·一次指数平滑（教材2.3.3）【教材｜掌握】

适用于无明显趋势、无季节波动的平稳时间序列。
$$F_{t+1} = \alpha Y_t + (1 - \alpha)F_t$$
  - $\alpha$：平滑系数，$0 < \alpha < 1$
  - $Y_t$：第$t$期实际观测值；$F_t$：第$t$期预测值

> 记忆要点：
> $\alpha$大→更加看重最新一期实际数据，响应快，波动大；
> $\alpha$小→看重历史预测，平滑性强，响应慢。
>
> 其他预测方法（了解即可，教材2.3.3末尾枚举，不作独立考点）：
> - 时间序列分析：ARIMA、SARIMA等（教材正文只详讲一次指数平滑）。
> - 机器学习算法预测：线性回归、逻辑回归、决策树、随机森林、神经网络（注意数据预处理与特征选择）。
> - 模拟（仿真）预测：定义变量与参数，用统计/运筹方法模拟不同情况。
> - 主观判断预测：基于专家经验与直觉，需评估专家背景、经验、意见。
> 区分：主观判断＝定性类；指数平滑＝时间序列定量类；回归＝因果类。
> 交叉引用：教材2.3.3将**线性回归**等机器学习算法列为预测方法（仅罗列算法名称，不展开模型原理）；完整一元线性回归模型本体（$y = ax + b$、最小二乘法、自变量/因变量）见【模块1 数学统计基础·1.1.5 回归分析·一元线性回归】。

> 交叉引用（不属本章）：**德尔菲法**（多名专家匿名、多轮反馈收敛的定性预测方法）教材第2版**第2章无原文**——2.3.3 只把「主观判断」作为一类预测方法提及、未列该方法名；其原文全文在**第2版 8.3.3 活动历时估算**（属软件项目规模估算五法之一）。2026-10-12 按**教材原文归口**将该考点移出本章、计入第8章，完整内容见【第08章 项目管理·模块3 进度管理】，本章不收录。

#### 3.1.4 决策的概念和过程（教材2.3.4）【教材｜了解】

- **决策的定义**：为实现特定目标，从若干可行备选方案中择优的思维过程。
- **决策过程四阶段**：情报活动（识别问题、收集信息、确定目标）→ 设计活动（拟定备选方案、状态分析与后果预测）→ 抉择活动（评估后果、选出满意方案）→ 实施活动（执行并跟踪修正）。前阶段不断受后阶段反馈修正。

> 记忆：决策四阶段＝情报→设计→抉择→实施。

#### 3.1.5 决策的方法（教材2.3.5）【教材｜了解】

教材列举的**定量决策方法**：线性规划、成本效益分析、效用分析、模拟仿真、决策树分析；教材仅对线性规划展开讲解（图解法与单纯形法），其余只列名（线性规划展开见本模块的3.1.6）。
- 成本效益分析：效益与成本折算为同一货币单位后比较。
- 效用分析：把方案效用转成数值比较。
- 模拟仿真：多次模拟得出平均效果与概率分布。

> 记忆：定量方法＝线性规划、成本效益、效用、模拟、决策树。

#### 3.1.6 线性规划：图解法与求解结果（教材2.3.5）【教材｜掌握】

> 适用场景：资源有限，求最大收益/最小成本。

1. 标准形式组成：目标函数+约束条件+变量非负
  - 目标函数：实现收益最大化或者成本最小化，由变量构成一次线性表达式
  - 约束：不等式/等式，描述资源上限、下限
  - 变量$x \ge 0$：资源数量不能为负数
2. 可行域：满足全部约束条件的变量取值集合。
3. **图解法**仅适用于2个变量（系分真题基本都是双变量）：画约束半平面得可行域，平移目标等值线到边界顶点取最优。
4. **求解结果的4种情况**：唯一最优解；无穷多最优解（两最优顶点连线上的点均最优）；无界解（无最优解，缺约束）；无可行解（约束矛盾）。后两种说明模型有误。
5. **顶点原则**：若存在最优解，一定在可行域某个顶点取得。

> 易错点：最优解不一定唯一；如果可行域无界，可能不存在最优解。
> 系分常考：线性规划最优解在可行域顶点；无穷多解/无界解/无可行解的含义；双变量图解。
> 注：教材2.3.5仅讲线性规划；整数规划、0-1规划教材未讲、真题极少，本讲义不展开。

#### 3.1.7 决策论：不确定型决策与五大准则（教材2.3.5未展开）【第1版补充｜掌握】

> 说明：教材第2版2.3.5仅把「决策树分析」列为一种定量决策方法，**不确定型决策准则在第2版第2章无任何文字**；整套内容源自第1版教程2.11.3决策论完整章节。近年频次窗未检出（0场），全量统计窗内2023上1道，按【第1版补充｜掌握】了解级降档处理：**不配置例题、不配置课后习题、不设易错点**，只掌握五准则的名称与取向。

【前置基础｜第1版补充】按决策环境分为三类决策：
- 确定型：环境唯一，直接计算
- 风险型：各自然状态有已知发生概率，计算期望收益
- 不确定型：未知自然状态发生概率，使用五大决策准则，**不可计算期望**

不确定型决策**五大准则**（在损益矩阵上选方案，源自第1版2.11.3）：
- 乐观准则（大中取大）：每种方案取最大收益，再选最大；
- 悲观准则（小中取大）：每种方案取最小收益，再选最大；
- 折中准则（赫尔威斯准则）：折中收益$H = \alpha \times R_{\max} + (1 - \alpha) \times R_{\min}$，其中$\alpha$为乐观系数，$R_{\max}$和$R_{\min}$分别为最大、最小收益。
- 等可能性准则（拉普拉斯）：把各自然状态出现概率视为相等，按各方案平均收益（期望）取最大；
- 最小后悔值（萨维奇）：先算后悔矩阵，每个方案取最大后悔值，选最小的那个。

> 备考提示：2021年后系分真题中，**不确定型决策近年频次窗未检出（全量统计窗内仅2023上1道）**，即便出题也只考五准则的识别与简单矩阵计算；五准则中乐观、悲观、折中、后悔值相对更可能考，等可能性（拉普拉斯）准则极少出题，仅作了解即可。
> 考点区分：风险决策有概率、算期望；不确定决策无概率、用五准则，不能算期望。

#### 3.1.8 典型易错点（线性规划）

1. 决策变量满足$x_i \ge 0$；资源约束的不等式方向不能写反；若存在最优解，一定在可行域顶点取得，且最优解不一定唯一。【🟡中频】
2. 两个顶点同时取得最优时，其连线上任意点均为最优解（无穷多最优解）；可行域无界时可能不存在最优解（无界解），约束相互矛盾时为无可行解。【🟡中频】

### 3.2 典型例题

**例题1【线性规划图解法】**

某工厂生产A、B两类服务组件。
- 生产A：消耗资源2，单位利润3；生产B：消耗资源3，单位利润4
- 资源总上限：12；产量约束：$x \ge 0, y \ge 0$
- 目标函数：$\max Z = 3x + 4y$；约束条件：$2x + 3y \le 12$，$x \ge 0, y \ge 0$
求最大利润。

```tikz
\begin{tikzpicture}[>=stealth]
  % 坐标轴
  \draw[->] (-0.4,0) -- (7.1,0) node[below] {$x$};
  \draw[->] (0,-0.4) -- (0,4.9) node[left] {$y$};
  % 可行域三角形 (0,0),(6,0),(0,4)，灰色阴影
  \fill[gray!18] (0,0) -- (6,0) -- (0,4) -- cycle;
  % 约束直线 2x+3y=12
  \draw[thick] (6,0) -- (0,4);
  \node[above right, font=\small] at (1.7,2.6) {$2x + 3y = 12$};
  % 目标等值线 3x+4y=18（最优，过 (6,0)、(0,4.5)）
  \draw[dashed] (6,0) -- (0,4.5);
  \node[above left, font=\small] at (4.4,2.0) {$3x + 4y = 18$};
  % 顶点
  \fill (0,0) circle (1.6pt);
  \fill (6,0) circle (2.2pt);
  \fill (0,4) circle (1.6pt);
  \node[below left] at (0,0) {(0,0)};
  \node[below] at (6,0) {(6,0)};
  \node[left] at (0,4) {(0,4)};
  % 最优解标注
  \node[above, font=\small] at (6,0) {$Z_{\max} = 18$};
\end{tikzpicture}
```

> 【解析】
> 线性规划图解法的最优解一定出现在可行域顶点。
> 可行域顶点：$(0, 0), (6, 0), (0, 4)$
> - $(0, 0): Z = 0$
> - $(6, 0): Z = 3 \times 6 + 4 \times 0 = 18$
> - $(0, 4): Z = 3 \times 0 + 4 \times 4 = 16$
> 对比得最优解 $x = 6, y = 0$。
> 【答案】最大利润18

**习题2【线性规划的求解结果】**

若某线性规划问题的可行域无界，且目标函数值可随变量增大而无限增大，则该问题的求解结果属于（）
A. 唯一最优解 B. 无穷多最优解 C. 无界解 D. 无可行解

> 【解析】可行域无界且目标函数可无限增大即为无界解（无最优解），源于缺乏必要的约束条件；两个顶点同时取得最优解时为无穷多最优解；约束相互矛盾时为无可行解。
> 【答案】C

**习题3【预测的方法】**

一次指数平滑预测$F_{t + 1} = \alpha Y_t + (1 - \alpha)F_t$中，平滑系数$\alpha$的取值越接近1，则预测结果表现为（）
A. 更依赖历史预测值、曲线更平滑 B. 更依赖本期实际观测值、响应更快 C. 预测值恒等于首期实际值 D. 预测精度必然提高

> 【解析】$\alpha$越大，赋予本期实际观测值$Y_t$的权重越大，对新信息的响应越快、曲线波动越大；$\alpha$越小越依赖历史预测值、曲线越平滑。$\alpha$取值不保证精度必然提高。
> 【答案】B

### 4.1 核心知识点精讲

#### 4.1.1 数学建模定义（教材2.4.3）【教材｜了解】

数学建模：运用数学的语言和方法，对实际问题抽象、简化，建立能近似刻画并解决实际问题的数学模型；经求解与分析，用模型结果解释实际问题并接受检验，若吻合较差则修改假设、重复建模，迭代优化后再应用。

#### 4.1.2 数学建模的过程（教材7步）（教材2.4.3）【教材｜了解】

教材把建模过程分为**7步**：模型准备（了解背景、明确目标、搜集信息）→模型假设（简化问题、抓本质、提出可检验假设）→模型建立（用数学语言刻画关系，尽量用简单工具）→模型求解（估算参数、解方程/优化/数值计算）→模型分析（误差分析、灵敏性/强健性分析）→模型检验（与实际比较，不符则修改假设重来）→模型应用。

> 真题如考步骤，**按教材7步作答**。

#### 4.1.3 模型分析（教材2.4.3）【教材｜了解】

- 误差分析：考察模型预测输出与真实观测之间的偏差。
- 灵敏度分析：考察模型输入参数变化，输出结果变化幅度。用来判断模型是否稳定。

#### 4.1.4 数学建模的基本方法（教材2.4.3）【教材｜了解】

教材给出建模的4种基本方法：
1. 直接分析法：根据对问题内在机理的认识，直接构造出模型。
2. 类比法：根据类似问题的模型，构造新模型。
3. 数据分析法：通过试验获得与问题密切相关的大量数据，用统计分析方法建模。
4. 构想法：对将来可能发生的情况给出逻辑上合理的设想和描述，用已有方法构造模型并不断修正完善。

> 记忆：直接分析、类比、数据分析、构想。

#### 4.1.5 数学建模的特点（教材2.4.4）【教材｜了解】

1. 逼真性与可行性（在“费用”与“效益”间折中）
2. 渐进性（由简到繁、删繁就简，反复迭代）
3. 强健性（假设/数据微小变化，模型结构/参数相应变化）
4. 可转移性（可跨领域借用，如生态/经济借用物理模型）
5. 非预制性（实际问题千变万化，模型不能做成预制品）
6. 条理性（促使分析更全面深入）
7. 技艺性（依赖经验、想象、判断，近乎艺术）
8. 局限性（结论的通用性、精确性只是相对和近似的）

> 记忆：逼真可行、渐进、强健、可转移、非预制、条理、技艺、局限。

#### 4.1.6 数学建模的分类：应用领域、数学方法、建模目的（教材2.4.4）【教材｜了解】

- 按应用领域：人口/交通/环境/生态模型等。
- 按数学方法：初等模型、几何模型、微分方程模型、统计回归模型、数学规划模型等。
- 按建模目的：描述、预报、优化、决策、控制模型。

> 模型按表现特征（连续/离散、静态/动态、确定/随机、线性/非线性）的细分见本模块的4.1.7；白箱/灰箱/黑箱模型见本模块拓展阅读。

#### 4.1.7 数学建模的分类·表现特征分类（教材2.4.4）【教材｜了解】

1. 按确定性
  - 确定性模型：输入确定，输出唯一（关键路径、线性规划）
  - 随机模型：含随机因素，输出是概率分布（贝叶斯、PERT、排队论）
2. 按时间
  - 静态模型：不随时间变化，同一时刻快照（线性规划）
  - 动态模型：随时间演变（排队论、差分方程）
3. 线性/非线性模型
  - 线性：变量一次，满足叠加原理；求解简单
  - 非线性：含乘积、高次项，求解复杂
4. 按变量性质
  - 连续模型：变量连续（如连续时间库存模型、连续概率分布）
  - 离散模型：变量取离散值（图论、组合计数、离散事件仿真）

1. 【数学统计基础·条件概率】已知$P(A) = 0.4$，$P(B \mid A) = 0.5$，则$P(A \cap B)$为（）
A. 0.2 B. 0.4 C. 0.5 D. 0.9

> 【解析】由条件概率定义$P(B \mid A) = \dfrac{P(A \cap B)}{P(A)}$，得$P(A \cap B) = P(A) \cdot P(B \mid A) = 0.4 \times 0.5 = 0.2$
> 【答案】A

2. 【图论·树与最小生成树】4个顶点的无向连通图构成一棵树，该图边数为（）
A. 2 B. 3 C. 4 D. 5

> 【解析】$n$个顶点的树边数为$n - 1 = 4 - 1 = 3$
> 【答案】B

3. 【图论·最短路径】关于Dijkstra算法，下列描述正确的是（）
A. 支持负权边 B. 求多源最短路径 C. 单源最短路径，且边权不能为负 D. 可检测负权回路

> 【解析】Dijkstra为单源最短路径算法，要求边权非负；Floyd为多源最短路径；Bellman‑Ford可检测负权回路。
> 【答案】C

4. 【图论·网络与最大流量】下列关于网络最大流的说法，正确的是（）
A. 最大流等于所有边容量之和 B. 每条可通路径的流量受该路径瓶颈边限制 C. 中间节点可截留流量 D. 最大流一定小于最小割容量

> 【解析】路径流量受该路径瓶颈边限制；中间节点只起转运、净流量为0；最大流值等于最小割容量（见模块2的拓展阅读）。

5. 【预测与决策·一次指数平滑】一次指数平滑中，平滑系数$\alpha$越大，则（）
A. 越看重历史预测值，曲线越平滑 B. 越看重最新一期实际值，响应越快 C. 预测值恒等于首期实际值 D. 与$\alpha$取值无关

## 二、计算题（1道）

1. 【图论·最小生成树 Kruskal】某连通无向带权图，顶点包含$A, B, C, D$；边：$AB(3), AC(1), BC(4), BD(5), CD(2)$。求最小生成树总权重。

> 【解析】
> Kruskal算法：边按权从小到大排序，依次选取**不构成回路的安全边**，$n$个顶点共选取$n - 1$条边。
> - 边升序排序：$AC(1), CD(2), AB(3), BC(4), BD(5)$
> - 依次选取安全边：$AC(1)$（无回路，选中）；$CD(2)$（无回路，选中）；$AB(3)$（无回路，选中）。
> 共4个顶点，选取$4 - 1 = 3$条边，停止选边。
> 总权重：$1 + 2 + 3 = 6$
> 【答案】6

## 三、简答概念题（1道）

1. 简述线性规划求解结果可能出现的4种情况及其含义。

> 【解析】①唯一最优解：在可行域的唯一顶点取得最优；②无穷多最优解（多重解）：两个顶点同时取得最优，其连线上任意点均为最优解；③无界解：可行域无界且目标函数可无限增大，即无最优解，源于缺乏必要的约束条件；④无可行解：约束条件相互矛盾，可行域为空。出现后两种情况一般说明线性规划的数学模型有错误。
