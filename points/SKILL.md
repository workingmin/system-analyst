# 系统分析师备考讲义编写技能

> **适用范围**：`points/` 目录下所有「第N章—xxx.md」系统分析师备考讲义。
> **权威性**：本文件是上述讲义新建、修订、校对和扩展任务的唯一权威规范。执行相关任务必须先遵循本技能；不得依赖已废止的外部讲义规范副本。
> **目的**：统一讲义的结构、命名、标注与书写规则，确保新建和修订文档格式一致，便于跨章对照、检索与维护。

## 技能概述与适用场景

本技能覆盖 `points/` 目录中所有符合「第N章—xxx.md」命名的系统分析师备考讲义，适用于：

- 新建章节讲义或章节内容；
- 修订、扩展、重组或校对现有讲义；
- 核对讲义是否符合考纲、教材、真题口径与本技能要求。

本技能本身包含完整规则，不依赖根目录旧规范文件。若用户明确要求仅做局部、受限修改，应遵循用户限定范围，并在不违反要求的前提下检查直接受影响的规范项。

## 执行流程

1. **确认目标与边界**：确定目标章节、用户要求和允许修改范围；不将无关章节或无关问题纳入改动。
2. **读取上下文**：阅读目标章节全文及必要的相邻章节、教材/考纲/真题资料，确认现有结构、术语与来源；不得仅凭文件名或旧内容推断。
3. **规划改动**：依据本技能确定需修改的章节位置、来源标签、考情同步项和可能受影响的题目/提示；遇到实质性歧义且无法从仓库资料判定时，先向用户澄清。
4. **实施改动**：按本技能及仓库既有命名、格式和行文习惯修改；只调整所需范围。不得编造教材出处、考纲条目、考频、真题内容或考试数据。
5. **同步核对**：知识点或考情发生变化时，检查并同步相关模块优先级、考情分析、易错点标记、例题习题、综合模拟题、来源说明与备考提示。
6. **交付前自检**：运行第9节自检清单，检查编号、引用、来源边界、题目排版和图示规范；检查最终差异及空白字符错误，确认无意外或无关改动。对无法核实的内容明确说明，不以猜测补齐。

## 证据与冲突处理

- **来源优先顺序**：现行考纲与可核实的系统分析师真题考情优先，其次为官方第2版教材原文；细则见下方「备考讲义设计总原则」。
- **不确定性处理**：缺少资料或无法核验时，不伪造引用、统计和结论；保留待核实标记或向用户询问所需材料。
- **规范冲突处理**：先核实是否属于适用范围、是否为用户的明确任务限定；本技能内部如存在无法协调的矛盾，不静默择一，应指出冲突并请求决策。
- **与旧规范的关系**：此前独立维护的讲义规范已并入本技能，后续只维护本文件，避免规则分叉。

# 备考讲义设计总原则（最高优先级，全库统一）

1. **第一优先级**：2024系统分析师考纲+2021年以后真题命题统计；**第二优先级**：官方第2版教材原文。

2. **考情基准（真题统计口径，全库统一）**：所有「考情分析」「模块优先级」「来源标签（真题高频/低频）」以及**总原则第4条「知识点分类规则」各判定条件中的考频表述**（高频/中频/低频/持续出题/反复外延命题/极少/从未出题）所依据的真题命题统计，**一律以2021年以后（近若干次）系统分析师考试真题变化动向为基准；2021年以前老真题的考频不作为任何分类判定依据**，并遵守：
  - **统计窗定义（两套区间对称）**：全量统计窗＝2021上～2026上（8场，对应 A 表『2021上～2026上题量/检出场次』列）；近年频次窗＝2024上～2026上（5场，跨2024/2025/2026三个自然年，对应『2024上～2026上题量/频次』列与来源标签判定）。两列区间式命名对称，弃用『近5年』『以来』等不精确表述。
  - 不以第1版大纲时代更早年份的老题考频替代现行考情——**「仅老真题出现」一律视同「2021年以后未考」**；
  - **不得引用其他考试（尤其信息系统项目管理师「高项」）的考情替代系统分析师考情**——两者命题频率差异显著，凡引用考情须标注所属考试与年份口径；
  - 旧版（第1版）仍保留、但新考情已弱化的考点，考频一律按2021年后实际命题重新核定，不沿用旧版「高频」标注。
  - **考情口径一致（四处）**：对同一模块，头部「考试形式」、模块优先级（🔴🟡🟢）、模块「考情分析」、文末「备考提示」对考频/重要度的判断必须一致；按2021年后真题重定考情后，须同步更新相关各处，不得只改其一。**真题量度一律用「题量（道）/频次（次）」表述，弃用「分值（分）」**；考情分析推荐标注2024上～2026上频次（如「2024上～2026上约X次/接近每次必考/中频/冷门」），以便各处对齐与后续复核。

3. **讲义 ≠ 教材摘要**：不需要复刻教材全部小节。教材只是参考资料，不是讲义必须全盘搬运。

4. **知识点分类规则**：

| 分类标签 | 判定条件 | 讲义处理方式 |
| --- | --- | --- |
| 【教材｜掌握】 | 教材存在；考纲明确要求且2021年以后真题高频/中频 | 进入模块核心知识点；可配典型例题、可出课后习题；Mermaid图；易错点 |
| 【教材｜了解】 | 教材存在；考纲有明确对应子项；2021年以后真题低频（2024上～2026上偶发≤2次或未考） | 编入模块核心知识点正文；概念要点＋记忆口诀为主；**不配例题、不配课后习题**；综合模拟题至多1道概念题；不设易错点 |
| 【教材｜非必学】 | 教材存在；考纲不明确，2021年以后真题极少/从未出题 | 放模块末尾「拓展阅读」，仅概念简述；**禁止配置例题、禁止配置计算习题** |
| 【第1版补充｜掌握】 | 第2版教材缺失/删减；**考纲明确OR 2021年以后真题持续出题（高/中频）或偶发出题（低频≤2次）**。教材第2版删减本身即官方弱化信号，故其「未考」档不保留了解级（与【教材｜了解】的有意差异，见「不收录」行） | 进入核心知识点；2021年以后真题高/中频的配例题、习题；**低频偶发的按了解级降档处理：概念要点＋记忆口诀为主，不配例题、不配课后习题、不设易错点（综合模拟题至多1道概念题）** |
| 【真题补充｜考频｜两版教材均无原文】 | 第1、2版教材均无原文，来自外部知识；**且按2021年以后真题考情分析判定需要收录**（不满足者不设本标签，按「不收录」行移除、不作备考范围）。按收录依据分两分支：①考纲明确但教材无对应章节（由 `第00章—考纲总纲.md` 指定归口章，**须收录**）；②考纲未明确但2021年以后真题反复外延命题（谨慎少量收录） | **两分支统一放归口章对应模块末尾「拓展阅读」**（不另设独立区块），小节首行注明收录依据（考纲归口/真题反复命题，见5.1第7条）；分支①要点＋少量选择题例题（拓展小节自带），不设课后习题；分支②谨慎少量收录，不配例题；**两版无原文但2021年以后考情判定不需要收录的（如仅偶发零星出现），不纳入本标签**，按「不收录」行移除，不作备考范围 |
| （不设标签，直接不收录） | 第2版教材缺失/删减，且2021年以后真题未考（**仅老真题出现视同未考**），考纲明确与否均适用；**含「两版教材均无原文＋不满足【真题补充｜考频｜两版教材均无原文】任一收录分支＋考纲存在」的空白区内容** | **不收录，一律移除，不作备考范围**（不进正文、不配例题习题、不进备考提示的知识点列举）；需留痕复核的，在该章头部「考纲定位说明」注明「考纲X.X：两版教材无原文且无2021年以后考情，不作备考范围」 |

5. 判定优先级顺序（**各档考频一律以2021年以后真题为口径，仅老真题出现视同未考**）：**考纲明确且2021年以后真题高频/中频 → 纳入核心正文（标【教材｜掌握】/【第1版补充｜掌握】）；考纲明确但2021年以后真题低频偶发（≤2次）→ 教材有的标【教材｜了解】；第2版删减的标【第1版补充｜掌握】并按低频降档处理（不配例题/课后习题/易错点）；第2版删减且2021年以后未考 → 不收录；考纲明确但两版教材均无对应章节/原文 → 归口模块末尾「拓展阅读」（标【真题补充｜考频｜两版教材均无原文】，注明收录依据：考纲归口）；考纲未明确但2021年以后真题反复外延命题 → 标【真题补充｜考频｜两版教材均无原文】谨慎少量收录（放拓展阅读，注明收录依据：真题反复命题）；考纲不明确且2021年以后真题极少 → 标【教材｜非必学】放模块末尾「拓展阅读」；考纲存在但两版教材均无原文、且不满足【真题补充｜考频｜两版教材均无原文】任一收录分支 → 空白区，一律移除，不作备考范围（需留痕的在头部「考纲定位说明」注明）。**

6. **「拓展阅读」内容不得进入各模块例题、课后习题与章节综合模拟题（拓展小节内自带的例题除外）。**

## 1. 文件命名与位置

- 文件名：`第N章—xxx.md`（N为两位数，如 `第01章`），存放于 `points/` 目录。
- 文件对应《系统分析师教程（第2版）》第N章；若新版教材章节与该章不一致，在文档头部「教材依据」中说明。

## 2. 文档头部（元信息区，必填）

开篇为「元信息+TOC」，顺序固定（三项元信息顺序不可调换）：

```
\# 系统分析师｜第N章 xxx（备考讲义+章节自测题）

\> \*\*教材依据\*\*：《系统分析师教程（第2版）》第N章 <章名>（共X节：N.1 <节名>｜N.2 <节名>｜…）。<与第1版的差异>；<教材外内容来源口径>。
\>
\> \*\*考纲定位说明\*\*：2024版考纲科目一「系统分析师综合知识」第N条 <条目名>（<子项1>｜<子项2>｜…，与教材第2版第X章各节<对应关系>）。
\>
\> \*\*考试形式\*\*：上午综合知识<单选题/＋计算题>；2021年以后真题约X～Y道；<章节地位>；案例分析、论文<地位>。
\>
\> 标签：系统分析师、上午题、<本章核心关键词…>

\[TOC]

\## 章节结构对照与来源标注
```

要求：

- 元信息用「引用块」逐条列出，每一条是独立 `> ` 行，顺序固定为「教材依据 → 考纲定位说明 → 考试形式 → 标签」，不得增删或调换。
- 三项元信息**各为单条引用块、单段书写**，块内不跨空行；只承载本章级总述，不写入模块级信息（逐模块来源标签、考情细则归第3、4节）。
- 三项均要求**可核验**：教材章节、考纲条目、真题题量/频次任何一项无法核实即不得虚构，须保留待核标记或向用户索取材料。各项必备要素与写法细则见 2.1～2.3。
- `标签` 行给出本章检索关键词，逗号分隔。
- `[TOC]` 之后**必须紧跟**「章节结构对照与来源标注」小节（见第4节）。

### 2.1 「教材依据」写法细则

**承载信息**：讲义溯源到哪本教材哪一章，以及教材版本变动与「教材外内容」的处理口径。

**必备要素（四项，缺一不可）**：

1. 教材全称＋版本＋章号章名：《系统分析师教程（第2版）》第N章 <章名>。
2. **教材节结构清单**：按教材原生编号列出该章全部一级节（`N.1 <原生节名>｜N.2 <原生节名>｜…`），节名用教材原文、不得自拟或缩写；该清单须与「章节结构对照与来源标注」表「对应教材第2版章节」列逐项互校。
3. **第1版↔第2版差异**：写明增/删/移出/移入/升格等变化（如"网络计划技术移入第8章"）；本章两版实质无变动时，也必须明确写"第1版/第2版实质知识点无变动"，不得省略不写。
4. **教材外内容的来源口径**：第2版删减但考纲要求或2021年以后真题仍考的，写明以【第1版补充｜掌握】/【真题补充｜考频｜两版教材均无原文】补回；本章无教材外补充时写"无教材外补充"。

**模板**：

`《系统分析师教程（第2版）》第N章 <章名>（共X节：N.1 <节名>｜N.2 <节名>｜…）。第2版<与第1版差异>；<教材外内容的补回/来源口径>。`

**细则**：单段、以「；」衔接各要素；节清单项之间用 `｜` 分隔；区间一律用全角 `～`，禁用半角 `~`。

### 2.2 「考纲定位说明」写法细则

**承载信息**：把本章锚定到2024版考纲的具体条目——这是"该不该学、学到什么程度"的官方依据，也是第3节模块优先级的源头。

**必备要素（四项）**：

1. 固定前缀「2024版考纲」。
2. **科目＋条目编号＋条目名**：科目一统一写作「系统分析师综合知识」第N条 <条目名>；编号取考纲科目1模块序号（1～18），**必须与 `第00章—考纲总纲.md`「科目1 综合知识」映射表一致**。科目二/三分写「系统分析师案例分析」「系统分析师论文」。**全文引用格式统一**：条目级一律写「考纲第N条」（多项并列写「考纲第N/M条」，简引场合也不得省略「第」「条」），禁止「考纲N」「考纲N/M」这类省略式——避免与「考纲N条（子项）」产生歧义；子项级用点分式「考纲N.M」（如考纲7.7、考纲1.6），点分式无歧义可省略「第」「条」。
3. **子项**：列出该条目下的考纲二级子项（考纲原文），用 `｜` 分隔；讲义只覆盖其中部分子项时，须点明覆盖范围。
4. **对应关系**：说明与教材本章的对应（一一对应／部分对应／教材未设对应）；考纲子项多于教材小节时，须点出"考纲有、教材无"的子项。

**特殊情形**：

- **考纲无独立模块条目的章（如绪论类铺垫章）**：改引【考试说明·考试要求】第(N)条，并明示"考纲无独立条目"，不得硬套一个模块序号。
- **一章覆盖多个考纲条目**：逐条列出并写明各自覆盖范围。

**强约束**：本节**只写本章对应的考纲条目**，不得夹带与本章无关的其他条目（无关条目统一在第00章总纲或对应章说明）。

**模板**：

`2024版考纲科目一「系统分析师综合知识」第N条 <条目名>（<子项1>｜<子项2>｜…，与教材第2版第X章各节一一对应）。`

**反例**：第2章旧文"……第17条 数学与工程基础（……）；第16条「经济、管理等相关知识」覆盖企业法律制度、财务成本管理、IT审计等。"——第16条与本章无关（其内容已分别归入第7/10/15章），属残留，应删除。

### 2.3 「考试形式」写法细则

**承载信息**：本章在三个科目中的考查形态与分量，直接决定备考投入比例。

**必备要素（四项）**：

1. **科目与题型**：统一用「上午综合知识／案例分析／论文」称谓；题型写单选题／计算题／案例简答／论文素材。
2. **真题量度（全库统一口径）**：一律采用**题量（道）/频次（次）**表述，**弃用「分值（分）」**；题量格式"<口径>真题约X～Y道"（极低频章可写"约0～X道"），频次格式"<口径>约X次"。口径统一写"2021年以后真题"（与总原则第2条考情基准一致），量纲须与各模块「考情分析」一致，不得混用"分"与"道"。可另附1年题例佐证。
3. **章节地位**：一句话概括（如"上午题单章权重最高章节之一""重中之重""几乎不考"）。
4. **跨科目地位**：说明该章在案例分析、论文中是作为考点、背景知识，还是几乎不涉及。

**模板**：

`上午综合知识<单选题/＋计算题>；2021年以后真题约X～Y道（<可选：某年题例>）；<章节地位>；案例分析、论文<地位>。`

极低频/偶发章可改用频次口径：

`上午综合知识<单选题>；2021年以后约X次；<章节地位>；案例分析、论文<地位>。`

**反例（口径不一致，须避免）**：

- "历年约1～2分"——既缺口径年份、又误用分值，应改"2021年以后真题约1～2道"。
- "2021年以后真题本章约2～3分"——误用分值，应改"约2～3道"。
- "2021年以后真题本章约8～9分/75分"——量纲不齐且误用分值，应写"约8～9道"。

## 3. 模块划分

- 章节正文按 **模块（`## 模块N：…`）** 组织，一个模块对应教材一个节（如 `X.X.X`、`X.X`）或一个逻辑主题。
- 模块标题统一标注「教材编号＋原生标题＋来源标签」，格式：

  `## 模块N：<模块名>（教材X.X.X）【来源标签】`

- **模块命名统一规则**（决定 `<模块名>` 取值，全库一致；以教材第2版原生小节名为基准）：

  1. **严格对应情形**（一个模块＝教材一个节/连续小节区间，内容基本为教材）：模块名**直接用教材原生节名（原文标题）**，不改写、不归纳。

  2. **真题/考纲拓展情形**（模块主体＝教材某节，为覆盖考纲或2021年以后真题高频而补充内容）：**模块名仍用教材原生节名，不因拓展改名**；补充内容由模块内三段式＋来源标签（【真题补充｜考频｜两版教材均无原文】/【第1版补充｜掌握】）承载，并在「考情分析」行说明拓展情况。

  3. **拆分/合并情形**（教材一节内容量过大需拆成多个模块，或多个子节合并为一个逻辑模块）：
    - 拆分：每个子模块用教材**子节原生名**，标注子节原生编号。
    - 合并：可用**逻辑主题名**（对多个子节的归纳），但必须在开头对照表「对应教材第2版章节」列**逐项登记所覆盖的全部原生子节编号＋原生标题**。

- **通用强制规则**：

  - 模块标题括号内的「教材编号＋名称」必须是**教材原生编号＋原生标题**，不得自拟、缩写、换词（「章节结构对照与来源标注」表的「对应教材第2版章节」列同此）。
  - 模块标题须与开头对照表「对应教材第2版章节」列相互对应（原生名/逻辑名各自标注清楚）。
  - 同一章内命名粒度一致：同属「拆子节」或「合并子节」的模块处理方式统一，不得混用；拆分/合并以内容量为依据，不强求机械一致。
  - 凡模块名为逻辑名/归纳名（与教材原生节名不同），必须在对照表登记原生名并备注归纳关系。

- 每个模块内部固定三段结构：

  `### N.1 核心知识点精讲` → `### N.2 典型例题` → `### N.3 课后习题`

- 若该模块含「教材存在但备考非必学」的内容，在三段式之后追加：

  `### 拓展阅读：教材原生但备考非必学内容`（【教材｜非必学】，仅概念简述，**无例题、无习题**）。

- 模块开头统一**三要素**（顺序固定：前置说明 → 模块优先级 → 考情分析），各独立成段、`**加粗标签**：`后接内容：

```
\*\*前置说明\*\*：本模块对应教材第2版第X章 <原生小节名>（<覆盖范围，可选>），<考纲条目>；<纳入内容来源说明>；适配<题型>。

\*\*模块优先级\*\*：🔴 高频（必考）/🟡 中频（中等）/🟢 了解为主（了解） —— <一句话依据>

\*\*考情分析\*\*（2021年以后真题）：<2024上～2026上频次/题量，如「2024上～2026上约X次（每年约1～2道）」>；核心考点：<考点关键词>。
```

**前置说明写法细则**：

- **称谓**：一律用「**本模块**」，禁用「本章」（模块级定位，不写整章通用套话）。
- **第一句（定位）**：对应教材第2版第X章原生小节（`X.X原生名`）；有考纲对应条目的写考纲条目（如 `<考纲条目>`）；考纲无对应同名条目（如绪论类概述）可只写教材小节。
- **第二句（纳入内容来源，可选）**：本模块含非教材原文内容时写（如「教材原文为主；某专题为【真题补充】；某专题为拓展了解」）；全部为教材原文可省略。
- **第三句（题型适配）**：上午综合选择题／计算题／案例题。
- **详略标准**：只写本模块**独有**定位信息；整章通用表述（「基于第2版教材、增补第1版删减但真题仍考」等）归入章首总说明，**不写入每个模块前置说明**。
- **模块优先级**：取 🔴（必考）/🟡（中等）/🟢（了解）之一，后接一句话依据。
- **考情分析**：行首统一标注 **（2021年以后真题）** 前缀；先写近年考频（推荐标注2024上～2026上频次：「2024上～2026上约X次/接近每次必考/中频/冷门」，亦可写「每年约X道」「偶尔1道」「几乎不考」；「近年」指 **2021年以后系统分析师真题**，口径见总原则第2条考情基准），再写核心考点关键词。**量度一律用「道/次」，与头部「考试形式」同口径，不用「分」。**

## 4. 章节结构对照与来源标注（必填，新增/修改都要维护）

位于 `[TOC]` 之后，用一张表+备注说明本章覆盖与边界：

```
\## 章节结构对照与来源标注

\> 本讲义为<教材第2版第N章>的学习讲义。说明本章哪些是教材内容、哪些是教材之外的补充。

\| 讲义模块 | 对应教材第2版章节 | 内容性质 | 备考要求 |
\|---|---|---|---|
\| 模块N <主题> | X.X.X <节名> | 教材/第1版补充/真题补充 | 掌握：…；了解：…；拓展：… |

\> 教材第2版第N章章节结构：<列出教材各节结构>。

\> ⚠️ 教材第2版第N章\*\*不包含\*\*：<按下方两源核查规则逐项列出，注明去向或讲义补回标签>；复习时注意区分，勿误当成该章本身内容。

\> 说明：<本章特有说明（如教材原文勘误提示、教材结构澄清等）；无则省略此块>
```

- 内容性质取值：`教材`（第2版本章原生）、`第1版补充`（考纲要求但第2版本章删减，源自第1版）、`真题补充`（两版教材均无原文，源自真题外延或教材无对应章节的考纲条目内容，由归口模块末尾「拓展阅读」承载）。
- **内容性质列写法细则（全库统一）**：
  - 单来源模块：直接取上述四枚举值之一，**不得另造变体**（禁用「主体为教材」「主体为X」「基本为教材」等自定义表述）。
  - 混合来源模块（同一模块以教材原生为主体、另含真题/第1版补充）：统一写作「主来源＋补充来源」，用半角 `＋` 连接（如 `教材＋真题补充`、`教材＋第1版补充`、`教材＋真题补充＋第1版补充`）；**禁止用自然语言长句、分号/顿号枚举来源**。
  - 本列**只承载「来源」**，不承载「掌握/了解/拓展」属性（一律归「备考要求」列）；【教材｜非必学】等属性**不写进本列**。
  - 「真题补充」（教材无对应章节的考纲条目内容）**不逐模块在本列标注**：此类内容归入归口章对应模块末尾「拓展阅读」，在该模块「备考要求」列以「拓展：…」登记，并在表下说明注明收录依据（考纲归口/真题反复命题）。
- **备考要求列**标明该模块哪些掌握、哪些了解、哪些拓展，取值与来源标签后缀（掌握/了解/非必学）一致，须与各小节来源标签对应。
- 每章有补充内容时保留 `⚠️ 不包含` 清单；若本章无补充，在表前说明「本章知识点几乎全部来自教材，无教材外补充」。
- **「⚠️ 不包含」清单的内容边界（待检查内容的两源核查，全库统一）**：清单功能＝**教材第2版本章的边界声明**——列出"考生复习材料中可能遇到、但不属教材第2版本章"的内容，逐项注明去向或讲义补回标签。待检查内容由以下两源确定，逐源核查：
  1. **第1版教材本章目录（必查，方向①版本差异）**：将第1版教材本章小节目录与第2版本章逐节对比，凡第1版有、第2版无（删除或移出他章）的内容**全部列入**，逐项注明去向（「第2版整体删除」／「移入第X章」／「第2版与考纲均已移出」）；讲义已补回的注明补回位置（如「讲义已以拓展阅读【第1版补充】补回」）。依据：考生材料清单含第1版教材，对照复习时必然遭遇这些内容。
  2. **本章考纲条目子项（必查，方向②考纲缺口）**：以 `第00章—考纲总纲.md` 归口为准，将本章考纲条目的子项全集与教材第2版本章小节对比，凡考纲有子项、教材本章无对应小节/原文的内容列入，注明讲义补回标签（【第1版补充】/【真题补充】）。
  - 清单是面向读者的边界声明，**不得作为讲义迁移/修订的审计记录**（「讲义历史上曾收录过什么」不构成列入理由）；**不设「相邻考纲条目」检查项**——条目归属以总纲为唯一权威，各章不得罗列归口他章的内容，避免多余检查诱发错误幻觉。
- **对照段内引用块分段与空行规则（全库统一）**：引言、教材章节结构、`⚠️ 不包含`、附带说明各自**独立成引用块（`>` 段）**，块与块之间**空一行**；每个引用块内**不跨空行**（单段；多行内容在块内以连续 `>` 行书写，行间不空行）。教材章节结构与 `⚠️ 不包含` 分属两个独立块；`⚠️ 不包含` 之后如确有本章特有说明（如拓展阅读收录规则、教材原文勘误提示、教材结构澄清等；**不得写跨章归口去向——条目归属以 `第00章—考纲总纲.md` 为唯一权威**），以独立 `> 说明：…` 引用块承接（块间空行），无则省略——**不把说明并进 ⚠️ 行，也不在 ⚠️ 与说明之间堆叠空行**。
- **`（按教材原文核读）`标记（可选）**：「教材章节结构」引用块行首的 `（按教材原文核读）` 为**校验标注**，仅当该段章节结构文本已直接对照《系统分析师教程（第2版）》教材PDF原文逐小节核对、确认编号与标题一致后才允许添加；未做此核对不得写入该后缀。核对时须遵守下方第183条「标题使用教材原文、不得自拟/缩写/改动」。
- **「对应教材第2版章节」列编写细则**：

  - 该列仅登记教材第2版本章**原生**章节/小节，值为「教材实际编号＋教材原文标题」；编号粒度（X.X或X.X.X）以教材实际编号为准，标题使用教材原文，**不得自拟、缩写或改动标题**。
  - 一个模块可对应单个节、连续小节区间或多个小节：均按教材原生编号升序逐项列出，多项之间用「｜」连接。
  - 教材原生之外的补充内容（第1版补充/真题补充）**不登记在本列**，改由「内容性质」列与文末 `⚠️ 不包含` 清单标注。

## 5. 来源标签规范（统一用【】）

在标题或要点前使用统一标签，全库一致：

| 标签 | 含义 | 示例 |
| --- | --- | --- |
| 【教材｜掌握】 | 第2版教材本章原生内容，且2021年以后真题高频/中频 | `#### N.N.N <知识点标题>（教材X.X.X）【教材｜掌握】` |
| 【教材｜了解】 | 第2版教材本章原生；考纲有明确对应子项；2021年以后真题低频（2024上～2026上偶发≤2次或未考） | `#### N.N.N <知识点标题>（教材X.X.X）【教材｜了解】` |
| 【第1版补充｜掌握】 | 第2版删减/未设、考纲仍要求或2021年以后真题持续/偶发出题，取自第1版；低频偶发的按了解级降档处理 | `#### N.N.N <知识点标题>【第1版补充｜掌握】` |
| （不收录） | 第2版删减/未设、2021年以后真题未考（仅老真题出现视同未考）；含「两版教材均无原文＋不满足【真题补充｜考频｜两版教材均无原文】收录分支＋考纲存在」的空白区 | 不设标签，一律移除，不作备考范围；需留痕的在头部「考纲定位说明」注明，不进正文/习题/备考提示 |
| 【真题补充｜考频｜两版教材均无原文】 | 第1、2版教材均无原文，来自外部知识；**且按2021年以后真题考情分析判定需要收录**：①考纲明确但教材无对应章节（须收录）；②考纲未明确但2021年以后真题反复外延命题（谨慎少量收录） | `#### 拓展·<知识点名>【真题补充｜考频｜两版教材均无原文】`（放归口模块末尾「拓展阅读」，小节首行注明收录依据）；两版无原文但2021年以后考情判定不需要收录的内容（如偶发零星）不纳入本标签，按「不收录」行移除 |
| 【教材｜非必学】 | 教材存在，但考纲不明确、2021年以后真题极少命题 | `### 拓展阅读` 内小节 |

- 标签写在标题尾部括号内或正文要点前，建议格式 `（教材X.X.X）【标签】`。
- **标签形式为封闭枚举（共5枚），组合方式唯一**：`来源标签`＋「全角｜＋备考要求」后缀（【教材｜掌握】【教材｜了解】【第1版补充｜掌握】【教材｜非必学】）；【真题补充｜考频｜两版教材均无原文】为固定三段式全名，**不得简写为【真题补充】**；混合来源用「＋」连接（如【教材＋真题补充】，同对照表「内容性质」列写法）。禁用「·」「/」「，」等分隔变体与自造名——「核心」属性由模块优先级与对照表「备考要求」列承载，考频由优先级标记（🔴🟡🟢）与条目考频标记（【🔴高频】【🟡中频】）承载，均不入标签。**【跨章节补充】已废除**（全部考纲条目已按第00章总纲唯一归口），不得再使用。
- **存量变体归一映射（修订对齐章节时执行；归一前不得再新增变体）**：【教材】（裸标签）→【教材｜掌握】；【教材核心】→【教材｜掌握】；【教材·了解】→【教材｜了解】；【教材/真题】→【教材＋真题补充】；【第1版补充】（裸标签）/【第1版补充｜了解即可】→ 2021年以后真题偶发出题（≤2次）的定【第1版补充｜掌握】（低频降档处理），2021年以后未考（仅老真题出现）的直接移除不收录；【跨章节补充】/【跨章节补充，高频】→【真题补充｜考频｜两版教材均无原文】（内容移入归口模块末尾「拓展阅读」；原「跨章节高频选择题拓展」及后继「考纲补充拓展」独立区块**废除**，不再单独设区）；【教材拓展｜非必学】→【教材｜非必学】（存量约11处，纯改名，位置仍为模块末尾「拓展阅读」）。
- 知识点分类详见「备考讲义设计总原则」第4条；【教材｜非必学】内容一律放模块末尾拓展阅读，不配例题习题；【教材｜了解】编入核心知识点正文，但不配例题、课后习题。

### 5.1 知识点标题（模块内 `####` 级）命名规范

统一格式：

`#### <模块编号>.<知识点序号> <知识点名>（<限定词>）（教材X.X.X）【<来源标签>】`

1. **编号**：`<模块编号>.<知识点序号>`，模块内知识点从 `.1` 连续编号；「典型易错点」小节是否设置**按实际考情设计**（见本节第6条），设则占模块内知识点之后的编号。

2. **知识点名**：名词短语概括考点；子主题用「・」连接（如 `<父主题>·<子主题>`），并列概念可用「：」（如 `<总主题>：<并列项1>、<并列项2>`）。

3. **限定词（圆括号，可选，置于教材位置之前）**：只允许三类 —— 数量（`N条`/`N阶段`）、适用范围（如 `离散随机变量`）、考点性质（`高频`/`概念区分`）；多个用逗号分隔；**此处不写教材位置**。

4. **教材位置（圆括号）**：置于限定词之后；凡知识点对应教材第2版**最小原生子节**，**必须标注** `（教材X.X.X）`；真题/归纳补充、教材无直接对应子节的，不标教材位置，改在【来源标签】标【真题补充｜考频｜两版教材均无原文】，或在限定词注明「教材X.X.X未展开」。

5. **来源标签【】**：置于最后，取值见上文来源标签表（【教材｜掌握】【教材｜了解】【第1版补充｜掌握】【真题补充｜考频｜两版教材均无原文】【教材｜非必学】），组合方式遵守标签表的封闭枚举规则。

6. **易错点类小节（按实际考情设计，非强制，全库统一为「典型易错点」）**：
   - **唯一标题**：`#### <模块编号>.<序号> 典型易错点（<所辖知识点范围>）`；**不设「高频易错点」等其他标题变体**。
   - **定位**：集中列做题典型易错/易混淆点（如同类术语、概念正误辨析）；**考频属于每条条目的属性，不上升为小节标题**。
   - **条目考频标记**：每条易错条目末尾标注其对应知识点的考频，`【🔴高频】`/`【🟡中频】`；标记须与该知识点模块优先级一致。
   - **「了解即可」（🟢/【教材｜了解】/按低频降档处理的【第1版补充｜掌握】）知识点的易错点一律剔除，不收录**，避免浪费备考精力。
   - **聚焦原则（冷门模块可省）**：冷门/几乎不考模块（2024上～2026上偶发1次、模块定位为了解即可）可不设易错点小节。
   - **考频一致性（纳入考情一致性约束）**：仅约束条目内考频标记与对应知识点一致；知识点考频更新时只改条目标记，**小节标题与小节是否设置均不随考频联动改动**。
   - **位置**：设则作为该模块知识点的最后一个小节。

7. **拓展阅读**：统一 `#### 拓展·<知识点名>（教材X.X.X）【教材｜非必学】` 或 `#### 拓展·<知识点名>【真题补充｜考频｜两版教材均无原文】`（拓展阅读收两类：【教材｜非必学】与【真题补充｜考频｜两版教材均无原文】，不收第1版补充类内容）。强制：凡有教材最小子节对应的知识点**必须带教材位置**；来源标签不可省略；后缀顺序固定为「限定词→教材位置→来源标签」。**【真题补充】拓展小节首行必须注明收录依据**，区分两种情形：分支①写「> 收录依据：考纲X.X（总纲归口本章），非真题考频判定」；分支②写「> 收录依据：2021年以后真题反复外延命题（注明年份依据）」。不得仅挂标签不注依据。

8. **拓展阅读小节排序规范**：同一「拓展阅读」区块内的多个小节，**一律按其对应教材小节编号升序排列**；第2版无对应小节的【第1版补充】内容，参照第1版教材对应小节编号，插入相邻位置；【真题补充】内容无法对应教材小节的，置于本模块拓展阅读末尾并保持位置稳定。禁止按备考热度/考点重要性另行排序。

9. **核心知识点精讲（`### X.1`）内部知识点排序规范（全库统一，强制）**：模块「核心知识点精讲」内 `####` 级知识点一律**按对应教材小节编号升序编排**（如 `X.1.1`→`X.1.2`→`X.1.3`→…），保持与教材翻阅顺序一致；**不引入按考情/考点重要度或教学逻辑另行重组的排序规则**（不因某考点考频更高、或为教学方便而把后编号知识点提前）。
   - **升序依据**：以知识点标题括号内标注的 `（教材X.X.X）` 最小原生子节编号为准，据此升序排列。
   - **无直接教材对应子节的内容**（【真题补充｜考频｜两版教材均无原文】【第1版补充｜掌握】等）：参照相近教材小节位置插入相邻处，保持整体与教材翻阅顺序一致；无法就近对应的，置于本模块知识点序列末尾并保持位置稳定。
   - **规范定位**：本条第8条约束「拓展阅读」区块内排序，本条约束「核心知识点精讲」内排序，两者合为全库统一排序原则：**凡有教材编号依据的知识点，一律按教材编号升序，杜绝「后编号知识点混插在先编号知识点之前」造成的溯源困惑**。

### 5.2 前置基础（背景铺垫内容）编排规范

前置基础指教材第2版本章**未直接展开、但为理解某知识点（或整个模块）所必需、或因2021年以后真题/便于考生理解而需插入**的背景概念。前置基础**不作为独立必考考点，默认不配例题、习题**（2021年以后真题高频的按常规标【真题补充｜考频｜两版教材均无原文】并纳入例题习题）。

**两种层级**（按作用范围区分，不二选一）：

- **模块级前置基础**：是理解**本模块多个/全部知识点共同需要**的背景定义（一套贯穿全模块的符号、分类、基本模型），不属于某个具体知识点的专属内容。

  - **编排位置**：`### X.1 核心知识点精讲` 标题之后、**第一个 `####` 子节之前**，作为独立铺垫段；**不设 `####` 标题、不分配虚构教材小节编号**。
  - **格式**：`### X.1 核心知识点精讲` → `【前置基础｜<来源>】<说明>` ＋ 基础定义列表 → `#### X.1.1 …`。

- **知识点级前置基础**：仅服务于**某一个具体知识点**（某一 `####` 子节）的前置概念，与模块其他知识点无共享。

  - **编排位置**：该 `####` 子节标题之后、正文展开之前，作为该子节开头的铺垫段。
  - **格式**：`#### X.1.N <知识点名>（教材X.X.X）【…】` → `【前置基础｜<来源>】<该知识点所需前置概念>` → 正文要点。

**来源标注**：`【前置基础】`可与来源叠加 —— 教材无原文、为通用/基础概念标 `【前置基础｜教材无原文】` 或 `【前置基础｜真题补充】`；教材有但略过、为理解而补标 `【前置基础｜教材】`；内容若实际来自教材某小节，可注 `（教材X.X.X）`。

**与「前置说明」区别**：模块头部 `**前置说明**` 是模块定位/来源/题型的总述（模块三要素之一），**不承载知识点内容**；`【前置基础】`段落承载具体的背景定义。两者位置与职责不同，勿混淆。

**边界**：若前置基础内容实际是教材某小节内容（有对应编号），应回归正常 `####` 知识点编排，不用前置基础形式；前置基础**不占 `####` 编号、不计入知识点序号**。

### 5.3 4级独立知识点（`####`）判定与标题命名细则

`####` 为讲义最小独立知识点单元，**不是对原教材目录做1:1镜像拆分**。是否拆分为独立4级知识点，以讲义自身知识点定位为核心依据；不满足独立单元条件的内容，收纳于就近上级4级知识点内部，通过正文段落、无序列表、引用块组织，**禁止新建5级标题（`#####`）作为正式知识点划分手段**。

#### 5.3.1 是否拆分为独立4级知识点（满足任一条件即应当拆分）

下列四项为**充分条件**，只要满足其中**任一条**，该子单元**必须拆分为独立4级标题**，不得合并进其他知识点：

1. **考情权重差异显著**：同一父主题下，该子单元与其余内容的模块优先级（🔴/🟡/🟢）存在明显区分，需单独标记优先级标签。

2. **可独立命题**：该内容能作为完整考点单独出题，而非仅作为其他考点的选项陪跑项。

3. **内容自洽完整**：具备「定义‑性质‑说明」的完整逻辑闭环，篇幅较长，适合独立阅读与复习定位。

4. **配套专属教学载体**：需单独配置例题、课后习题或拓展演算。

反过来说，**只有同时不满足以上全部四项**，才**不得**新建独立4级标题，此时内容收纳于就近上级知识点内部，用列表/引用块承载子要点；**禁止为教材罗列的名词清单批量创建碎片化4级知识点**。

#### 5.3.2 标题分隔符号语义与格式约束

仅当已判定需拆为独立4级时才使用；不拆则内容在正文组织，不使用两类符号。

1. **间隔符「·」——父子主题剥离关系**：`父主题·子主题`，从明确父主题中剥离出单一子主题作为独立知识点；**强约束：`·` 之后只能为单个子主题，禁止放置多个并列条目，不允许出现 `父·A、B、C` 形式**。

2. **冒号「：」——同主题内并列集合关系**：`总主题：并列项1、并列项2`；整个知识点单元为独立4级，单元内包含若干平行子对象，子对象不再各自拆为独立4级；**强约束：冒号后为一组同层级并列对象，冒号之后不再嵌套使用「·」**。

同一标题内二者只选其一，不可混合嵌套使用。

#### 5.3.3 标题内容溯源约束

1. 优先复用教材原生小节/子小节名称作为标题骨架；

2. 讲义归纳重组的自定义主题不可完全脱离教材语义，须依靠知识点的来源标签（【教材｜掌握】/【第1版补充｜掌握】/【真题补充｜考频｜两版教材均无原文】）标明内容来源；

3. **禁止使用「其他」「其余」等模糊兜底词作为4级标题的正式主题名**；零散低权重子要点放正文内部列表处理。

#### 5.3.4 拓展类知识点固定前缀约束

拓展类知识点统一固定前缀 `拓展·`；其后续标题文本同样遵循5.3.2、5.3.3全部约束。

## 6. 内容书写规范

- **聚焦原则（低价值内容处置）**：讲义以备考效益为先，**坚持聚焦而非发散**。

  - 凡**教材（两版）无原文、无2021年以后现行考情支撑**的知识点——含「考纲无明确条目＋真题非反复命题（仅偶发零星出现）」与「考纲存在但两版教材均无原文、不满足【真题补充｜考频｜两版教材均无原文】收录分支的空白区」——**一律直接移除，不作备考范围**：不收录正文、不配例题习题、不设刷题提示、不进备考提示知识点列举，以免分散考生精力。

  - 仅当真题**反复外延命题**（近几次考试多次出现同类考点）时，才按 `【真题补充｜考频｜两版教材均无原文】` 谨慎少量收录；**考纲明确但两版教材均无对应章节的条目考点不受"反复命题"限制**，按归口约定收录进归口模块末尾「拓展阅读」并注明收录依据（考纲归口）。

  - 模块级前置基础**只保留阅读教材正文例题所必需的最低限度符号/术语**；连这一最低限度都不需要的，连同移除。

  - **例题/习题/综合题与考频匹配**：按2021年后真题重定考情后，须同步复核各模块例题、课后习题与章节综合模拟题数量——高频模块正常配置；中频模块适量；冷门/了解为主模块大幅精简（可保留少量助理解的核心概念题，不堆量、不设复杂计算题），避免投入与考频不匹配。

- **公式**：行内公式用 `$…$`，独立公式用 `$$…$$`；分布表、算法表优先用Markdown表格。

- **编号引用与量词书写规范（全库统一）**：
  - **编号引用后禁止直接拼接量词/数量短语**：「模块N」「例题N」「习题N」「知识点N.N」「第N章」「考纲第N条」等编号引用与其后的量词之间，须以「的」或标点分隔，避免把编号误读为数量——写「对照表中模块5所在的行」「模块1的核心知识点」，不写「模块5行」「模块1核心知识点」。数量短语**前置于**名称不受限（「2道例题」「5个模块」）。
  - **章号与节号不得无分隔连写**：引用教材节号写「教材3.6.7」（节号自带章位，推荐）或「第3章的3.6节」（须有「的」）；「第3章 3.6」式（空格分隔）仅限同一行文内已明确教材语境时使用，不得写成「第3章3.6」。
  - **行文章号一律不零填充**：行文引用写「第1章～第21章」；零填充形式仅用于①文件名与文件路径（`第01章—绪论.md`，保排序）、②「第00章」（总纲专名）。多章并列沿用斜杠式「第7/15章」，多条并列「考纲第14/15条」。

- **KaTeX内容边界与空格（全库统一）**：
  - 只把数学表达式、变量、数学符号和具有数学含义的字母标识放入KaTeX；普通数字（如「4个顶点」）、普通英文缩写/名称（如MST、Dijkstra）及一般文字不加数学定界符。单独变量或数值只有在作为数学对象、参与表达式或表示数学量时才使用KaTeX。
  - 中文与行内公式相邻时不强制留空格（如「概率$P(A)$」）；英文单词与公式相邻时按英文排版留一个半角空格。句读标点放在公式定界符外，除非该标点本身属于公式。
  - 公式源码中，二元算术、关系及逻辑运算符两侧各留一个半角空格（如 `$x + y = 1$`、`$P(A) > 0$`）；函数名与参数、括号与内容、上下标与主体之间不加空格（如 `$P(A_i)$`、`$x_i$`）。逗号分隔的变量、参数或集合元素统一使用「逗号+一个半角空格」（如 `$A_1, A_2, \dots, A_n$`、`$\{u, v\}$`）。普通源码空格不负责制造额外数学间距；只有确有排版语义时才使用 `\,`、`\quad` 等命令，不用它们补救源码格式。
  - **相邻数学片段合并**：同一中文短语中，若连续列举或并列的项目都是数学对象，中间没有需要保留在公式外的中文说明，则合并为一个行内公式，并在公式内用数学逗号和一个半角空格分隔，例如「事件$A, B$」「常数$a, b$」「参数$A_1, A_2, \dots, A_n$」。若数学对象之间夹有各自的中文谓语或说明，则不要跨越中文强行合并，例如「$S$属于集合$A$，$T$属于集合$B$」；公式边界应跟随语义结构，而非追求最长片段。
  - **KaTeX内中文**：中文解释、单位和注释优先放在数学定界符外；不得将裸中文直接写进数学模式。只有当中文注释必须与公式作为一个整体排版时，才在数学模式中用 `\text{…}` 包裹中文，例如 `$P(A) = 0.5 \quad \text{（A 发生的概率）}$`；如需突出公式变量，优先把变量写在公式主体中，避免把变量混入中文文本。中文文本不应长篇嵌入公式；KaTeX可在文本模式接受中文，但字形由系统字体提供，可能与KaTeX数学字体不完全协调，须在目标MPE预览环境检查基线、间距和换行。
  - **集合记法（全库统一）**：KaTeX 官方支持表在「Logic and Set Theory」列出 `\set{…}` 和 `\Set{…}`，并不表示官方偏好其中一种；二者都是KaTeX支持的集合构造命令。为兼顾数学符号的常见写法和不同TeX渲染器的可移植性，本库统一用显式花括号书写：枚举集合用 `$\{A, B\}$`，集合构造式用 `$\{x \mid x < 5\}$`；需要随内容伸缩的花括号用 `\left\{…\right\}`。不在同一讲义中混用 `\set`、`\Set` 与显式花括号。图论统一写作 `$G = (V, E)$`，顶点/边集合成员分别用 `$v \in V$`、`$e \in E$`；无向边用无序对 `$\{u, v\}$`，有向边可用 `$(u, v)$` 或 `$u \to v$`，全文同一场景保持一致。为压缩边清单，可约定 `AB(3)` 表示端点为A、B且权重为3的无向边，`S \to A(3)` 表示有向边及其权重；清单中仍应将这类符号整体放入KaTeX。

- **分式（全库统一）**：全部分式统一使用 `\dfrac{分子}{分母}`，**不使用 `\frac`**；该规则覆盖行内公式、独立公式，以及根号、括号、求和等嵌套内部的分式，保证全书分式显示大小一致、便于阅读与打印。

- **字符使用（区间表达，全库统一）**：半角波浪号 `~` 是Markdown **删除线语法标记**，**禁止用半角 `~` 表达章节/版本/数量区间**（如 `X.X.X~X.X.X`、`1~2分`）——解析器会把 `~…~` 误渲染为删除线（小字划掉），造成排版错乱。区间「从…至…」一律使用**全角波浪号 `～`**（U+FF5E），示例：`（X.X.X～X.X.X）`、`1～2分`；仅当确需删除线效果时才使用半角 `~~内容~~`。凡用半角 `~` 表达区间的旧写法（含 `\~` 转义写法）应统一改为全角 `～`。

- **列表缩进（全库统一）**：数字序号项（`1.`/`2.`/…，顶格）下的 `-` 子列表项缩进 **2个半角空格**（`  - 要点`）；`-` 子列表项下的补充说明（注意/例如/区分等）用引用块 `  > 说明`（缩进 **2个半角空格**+`>`）。顶层无序列表（无上级编号）`-` 保持顶格；数字序号项本身顶格。

- **图表**：涉及流程、结构、比较、算法步骤时用 `mermaid` 代码块（如 `graph LR`、`graph TD`）可视化，并配文字说明。

- **记忆**：每个高频考点后建议加 `> 记忆：<口诀>` 引用块。

- **易错点（按实际考情设计，非强制，全库统一「典型易错点」）**：小节统一命名 `#### <编号> 典型易错点（<覆盖范围>）`，不设「高频易错点」变体；是否设置按实际考情（冷门可省）决定；条目末尾标注对应知识点考频【🔴高频】/【🟡中频】，**「了解即可」（🟢/【教材｜了解】/按低频降档处理的【第1版补充｜掌握】）知识点的易错点剔除不收录**（规则见「5.1 知识点标题命名规范」第6条）。小节集中列易混淆点（如同类术语/概念的正误辨析）。

- **优先级**：用 🔴🟡🟢 标注考点重要度；用【高频】【低频】标注出题概率；低频内容明确提示「了解即可/真题遇见可跳过复杂计算」。

- **跨章边界提示**：某内容虽在别处有详解，仍用「> 注意：… 勿混淆」提示，标注 `<跨章易混淆的相似概念>`。

## 7. 例题与习题规范

- **排版范式（全库统一，例题/课后习题/综合模拟题三处一致）**：题目区块采用 **「区块间单空行分隔」**——`**标题**` → 空行 → `题干` → 空行 → `【解析】引用块（含【答案】）`。即：标题与题干之间空一行、题干（含选项）与解析引用块之间空一行；【解析】与【答案】为**同一引用块的连续两行、中间不空行**；两道题之间空一行。
  - **边界细则（强制）**：
    - 区块之间**恰好1个空行**，禁止连续两个及以上空行；
    - 【解析】引用块内部（【解析】与【答案】之间）**不允许空行**，保持连续引用块；解析多行时各行以 `>` 开头，列表项用 `> - `；
    - 选择题（短题干）与计算题（长题干）使用同一套排版规则，不搞两套规则；
    - 题干含代码块（如 `viz` 图）时，代码块与题干、与解析引用块之间也各空一行。

- **选择题选项排版（全库统一）**：选择题选项**默认同行排列**，各选项之间以**一个半角空格**分隔（如 `A. 甲 B. 乙 C. 丙 D. 丁`）；**仅当单个选项文本过长、一行放不下时才改为竖排**（每个选项独立成行）。规则要点：
  - 同行选项之间一律**单半角空格**，禁止使用双空格、全角空格或制表符作为选项分隔；
  - 「选项过长」以实际排版可读性为准：短选项（短语、数字、名词）一律同行；明显过长（长句/含完整分句）的选项才竖排；
  - 同一章节内相邻题目不要无谓混用同行与竖排；同类短选项题全章统一同行，同类长选项题全章统一竖排。

- **标题后缀（全库统一，简洁、默认不加括号注释）**：例题用 `### N.2 典型例题`，课后习题用 `### N.3 课后习题`，综合模拟题用 `# 章节总复习综合模拟题`；「真题同源」「带完整解析」等为内容固有属性，**不写入标题**（确需补充说明时可作括号注释，属例外）。

- **例题题目格式**：知识点主题用【】标注在**例题标题行**（`**例题N【<知识点主题>】**`，不用冒号）；**【】内知识点主题直接写名词短语、不加括号注释**（不使用 `**例题N【<知识点主题>（<分类>）】**` 这类带括号写法）；选择题题干段内题干与选项同一段。排版遵循「区块间单空行分隔」范式，格式：

  ```
  \*\*例题N【<知识点主题>】\*\*

  <题干>（计算题题干可多行；选择题题干后接A.…、B.…选项）

  \> 【解析】<解题思路>
  \> 【答案】X
  ```

- **课后习题题目格式**：`**习题N**`（标题行），不强制标注知识点，如需标注用 `**习题N【知识点】**`（【】内同样直接写知识点名、不加括号注释）；每题答案解析用与例题一致的引用块；排版遵循「区块间单空行分隔」范式（标题→题干→解析块各空一行）。

- **解析与答案标注（例题、课后习题、综合模拟题三处统一）**：一律用引用块 `> 【解析】` 与 `> 【答案】`；**不使用** `> 解析：`/`> 答案：` 等其他变体。

  - 【解析】与【答案】为**同一引用块的连续两行，中间不空行**；解析多行时各行以 `>` 开头，列表项用 `> - `。
  - 题目段（含选项）与引用块之间**空一行**；两道题之间空一行。

- **综合模拟题**：章节末尾独立为 `# 章节总复习综合模拟题`，分三部分：`## 一、单项选择题（N题）`、`## 二、计算题`（如有）、`## 三、简答概念题`。

  - 各节题目一律**直接跟随二级标题**，以 `1. …` 编号列表项书写；**不在 `##` 下再建三级标题，也不插入独立标识行**。
  - 需标注题型/子类标识时，将该标识作为**题目列表项的行内前缀**，格式如 `1. 【<题型/子类标识>】<题目…>`。
  - 每题答案解析用 `> 【解析】`+`> 【答案】`，紧跟在题目列表项之后（题目与引用块间空一行）；排版遵循「区块间单空行分隔」范式。

- 多选题/辨析题：同类复杂易混概念建议出对比型题。
- 来源标注：补充内容的习题，解析末尾标注来源简标 `【教材原有】/【第1版补充】/【真题补充】`（对应第5节标签的来源段），便于错题复盘定位。
- **拓展阅读的知识点不得出现在各模块例题、课后习题与综合模拟题中（拓展小节内自带的例题除外）。**

## 8. 结尾「备考提示」

文末以 `---` 分隔，用引用块收尾：

```
\> \*\*备考提示\*\*：本章<题量/题型概况>，重点掌握：①…；②…；③…。其余内容以理解为主，不必死记。
```

- 题量与题型口径须与头部「考试形式」一致（统一写「2021年以后真题约X～Y道」，低频章可写「2021年以后约X次」），不得另用「分」或「X分/75分」等其他量纲，避免同章两处口径不一。

## 10. 插图绘图规范（MPE原生代码块）

> 适用范围：本讲义所有插图。
> 环境约束：默认场景为 **VSCode+Markdown Preview Enhanced（MPE）**，面向同类使用者圈层内预览阅读；**不引入外部GUI绘图工具**（排除GeoGebra、draw.io、PlantUML），不依赖外部SVG图片引用。
> 风格约束：**黑白印刷风** —— 白底、黑色线条、黑色文字，不依靠颜色区分元素，靠线型/形状/标签区分。

### 10.1 绘图引擎全集与分工（四类代码块，全库唯一）

| 图类型 | 代码块标记 | 用途 | 备注 |
| --- | --- | --- | --- |
| 简单概念框图、流程、时序、状态图、ER图、甘特图 | `mermaid` | 概念逻辑框图、流程 | 块首固定黑白初始化；**禁止curve弧线** |
| 图论网络图：无向/有向图、最小生成树、最短路径、网络最大流、AOE‑PERT网络图 | `viz {engine="dot"}` | 带权重、交叉边的图论例题 | DOT源码开启 `splines=curved; node [shape=circle];` |
| 平面几何/集合图：可行域阴影多边形、集合相交图 | `tikz` | 几何绘图、相交集合图形 | 仅用于少量拓展插图 |
| 统计折线图：时间序列多序列对比 | `vega-lite` | 折线图表 | 不依赖颜色，靠 `strokeDash` 线型区分序列 |

- 简单优先原则：能用mermaid搞定的简单框图优先mermaid；带权重、交叉边的图论网络图交 `viz(dot)`；平面几何、集合相交图交 `tikz`；统计折线交 `vega-lite`。
- tikz只用于少量拓展插图（集合相交图、图解类图形），**不把复杂3D伪立体图放进tikz**（复杂立体示意改用mermaid二维简化框图），控制TikZ代码总量，避免渲染卡顿与维护成本。

### 10.2 Mermaid统一样式（黑白印刷，强制）

- 固定使用 `theme:base`，配套完整 `themeVariables`，强制白底、黑色线条、黑色文字，杜绝主题自带浅紫/浅蓝底色与彩色线条。
- 主题变量书写顺序固定：主填充 → 文字 → 边框 → 连线 → 次级/三级背景 → 子图背景。
- 基础黑白模板（无子图）：

  ```mermaid
  %%{
  init: {
    "theme":"base",
    "themeVariables": {
      "primaryColor":"#ffffff",
      "primaryTextColor":"#000000",
      "primaryBorderColor":"#000000",
      "lineColor":"#000000",
      "secondaryColor":"#ffffff",
      "tertiaryColor":"#ffffff"
    }
  }
  }%%
  graph LR
    T[节点A] --> H[节点B]
  ```

- 若框图包含 `subgraph` 子图，启用扩展版，额外设置 `subgraphColor:"#ffffff"`、`subgraphBorderColor:"#000000"`。
- 仅用于简单概念框图、流程；**禁止使用mermaid高级curve弧线配置**（版本兼容性差）。

### 10.3 Graphviz图论网络图（viz标记）

- 代码块围栏标识固定使用 `viz`；块选项显式声明 `{engine="dot"}`（如切换环形/弹性布局，只改 `engine` 参数，块标识保持 `viz` 不变）。
- 概念区分：`DOT` = 绘图描述语言（块内文本）；`viz` = MPE代码块标记（调用Viz.js渲染器）；`dot(engine)` = Graphviz布局引擎名。
- 布局规范：若无特殊理由，优先设置 `rankdir=LR;` 使用横向布局，减少纵向占用。
- 统一模板：

  ```
  digraph G {
    rankdir=LR;
    splines=curved;
    node [shape=circle];
    A -> B [label="6"];
  }
  ```

- 开启 `splines=curved;` 实现平滑弧线（Graphviz原生稳定，规避mermaid‑curve版本坑）；`node [shape=circle];` 绘制圆形顶点，适配图论例题。

### 10.4 TikZ（平面几何/集合拓展插图）

- 可行域图解：绘制坐标系、约束直线、多边形填充阴影。
- 集合相交图：调用 `\usetikzlibrary{venn}` 绘制多个圆相交；**变通处理：图内分区只标注数字编号，集合公式与文字含义放到下方Markdown表格**，图文解耦、绘图代码简洁、易维护。
- 定位：此类插图均属【教材｜非必学】，正文优先用文字/表格承载考点，图仅辅助理解，真题不考识图。

### 10.5 Vega‑Lite（统计折线图拓展）

- 用于时间序列多序列对比折线，**完全依靠线型区分序列，不使用颜色**：

  - 实线：实际观测值；
  - 长虚线 `strokeDash:[8,4]`：参数甲 预测值；
  - 点虚线 `strokeDash:[2,2]`：参数乙 预测值。

- 全部线条黑色，`config` 中坐标轴、网格保持黑白；插图下方必须配图注说明每种线型含义。
- 定位：拓展插图，正文优先保留教材原始数据表与计算公式。

### 10.6 拓展插图的变通原则

- 凡判定为【教材｜非必学】的插图，允许变通实现：图形仅表达拓扑/位置关系，复杂公式、文字释义迁移至下方表格，不必全部堆砌在图形内部。
- 若图形仅为辅助展示、考点完全可由文字/表格承载，允许直接移除插图，不强制绘图。
- 原版3D伪立体示意图不强行绘制：教学正文用mermaid二维概念框图+结构化表格承载考点；考试一般不考识图。
