## 四、变化类型与规则代码说明

### 4.1 变化类型（稳定词表）

| 类型 | 语义 |
| --- | --- |
| 对应 | 两版同主题、同层级、编号相同或等价，内容主体延续 |
| 同号改题 | 编号相同，节题改写（主题延续） |
| 同章位移 | 同一章内编号位移（主题延续，位置调整） |
| 跨章移动 | 移至另一章（须有章对应依据） |
| 拆分 | 一个第1版节的内容分入多个第2版节 |
| 升格 | 第1版下级节在第2版成为更上级节（如三级→独立二级节） |
| 降格 | 第1版上级节在第2版成为更下级节 |
| 并入 | 内容收编于某一第2版节（该节另有多方来源或为父节落点） |
| 随父节移动 | 父节已定落点，本子节随父节同移（近名/同名定位） |
| 重构保留 | 节重组后主题以新形式保留 |
| 删除 | 第2版无对应内容（核心词 0 命中或仅 incidental 提及，证据见依据列） |
| 新增 | 第2版有、第1版无对应来源的节 |
| 整章新增 | 第2版全新章（章级认领覆盖其全部小节） |
