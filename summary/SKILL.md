# 考点总览类文档治理规范

> **适用范围**：`summary/` 目录下两份考点总览文档——《综合知识考点总览.md》《计算题考点总览.md》。
> **权威性**：本文件是上述文档新建、修订、校对任务的唯一权威规范。`notes/SKILL.md`（忠实层）与 `points/SKILL.md`（讲义）不在本技能范围；三技能互不越界，本技能的治理规则不得回流写入其他技能。
> **职责边界**：本技能只管考点总览类文档治理；不管 notes/ 文档维护、不管讲义编制。

## 一、文档清单与定位

| 文档 | 组织轴 | 内容权威来源 |
|---|---|---|
| 《综合知识考点总览.md》 | **章节轴**总览——按2024版考纲科目一条目顺序逐条梳理 | 2024版考纲＋教材第2版＋2021年以后真题考情 |
| 《计算题考点总览.md》 | **考频轴**总览——同一考点聚合其两科出题形式 | 同上 |

- **定位**：考情治理视图，作为讲义编制的上游考情参照；允许按考情复核更新，但须遵守本规范统一治理要素。
- **文件名为固定标识符**：文内交叉引用均按文件名指路，改名会破坏引用链，原则上禁止改名。

## 二、四项公共治理要素（强制）

**版式不跨文档强求统一**：版式由组织轴决定——章节轴文档（《综合知识考点总览》）用 css 自动编号＋`[TOC]`；考频轴文档（《计算题考点总览》）用分级表格。统一版式会迫使组织轴扭曲，故本节只约束以下公共要素：

1. **头部元信息块**：标题之后、正文之前，引用块逐条列出：适用科目、教材基准（《系统分析师教程（第2版）》）、考情口径、文档定位（组织轴说明＋与其它总览文档的分工）。两份总览文档的头部要素须对齐，不得一份有一份无。
2. **考情口径**：全文档考频表述（高频／中频／低频／历年／稳定出题等）一律以**2021年以后系统分析师真题**为统计口径，在头部「考情口径」行统一声明，不必逐行标注；分值类表述须保留「非官方统计、实际浮动」声明。
3. **编号引用规则**：条目级引用写「考纲第N条」、子项级「考纲N.M」；行文章号不零填充（写「第2章」）；编号引用后禁拼量词（以「的」或标点分隔）；区间一律用全角「～」。
4. **名称与引用一致性**：教材章名、考纲条目名一律以 `points/第00章—考纲总纲.md` 为准（不得出现章名漂移）；文内交叉引用提及的文档、区块、小节须真实存在；「讲义对应」指向的讲义承载形式须与讲义现行规范一致（现行规范：归口模块末尾「拓展阅读」＋收录依据标注；旧「跨章节高频选择题拓展」独立区块已废除，引用时不得再使用旧区块名）。

## 三、编制后自检

- [ ] 头部四要素齐全，且与另一份总览文档对齐。
- [ ] 全文无缺口径的考频断言（「历年」「高频」等均在头部口径覆盖之下）。
- [ ] 编号引用合规（考纲第N条／章号不零填充／编号后不拼量词／全角～）。
- [ ] 教材章名、考纲条目名与 `points/第00章—考纲总纲.md` 逐一比对无漂移。
- [ ] 交叉引用的文档与讲义区块实际存在，且为现行形态（拓展阅读＋收录依据）。
- [ ] 格式体检通过：标题前后空行齐备、无行尾空白、无连续空行、无半角「~」区间。
