# 考情素材类文档治理规范

> **适用范围**：`exams/` 目录下的考情证据类文档（不枚举具体文件，见第一节类属管辖）。
> **权威性**：本文件是本类文档新建、修订、校对和扩展任务的唯一权威规范。执行相关任务必须先遵循本技能。
> **职责边界**：本技能只管 `exams/` 目录内的文档治理。除第一节声明的单向上游依赖（`notes/`）外，本规范自洽自立，不规定、不依赖、不引用本目录以外的任何文档及其组织结构；目录外的其他变更均不引起本规范的维护动作。

## 一、目录职能与类属管辖

**职能定位**：`exams/` 是**素材层**——按考试场次与题目两个粒度，固化"哪一场考了什么、据何来源"，并登记"来源本身"。它是考情分析的**证据侧**，只记事实，不产出结论侧内容。

**上游依赖（单向）**：本目录的判定基准来自上游——考试范围以 `notes/`（考试大纲抽取件）为准，章节坐标以《系统分析师教程（第2版）》目录为准。本目录只**读取**上游提供的范围与坐标，不反向规定上游的内容与结构；依赖单向、无循环。

**职责边界（自持）**：凡属考频分级、优先级判断、讲义编排等**结论侧与编写侧**的产出，均不在本目录职责范围内。本目录不声明、不规定这些产出的承载位置，也不与之互相引用——以此杜绝"素材引结论、结论回填素材"的循环依赖。

**类属管辖原则**：以**文档类别**而非文件清单划定管辖——符合下列四者之一即自动纳入管辖，本规范不维护文件清单，新增同类文档不引起本规范改动：

1. **逐场考情实录（场次轴）**：以考试场次为最小条目单元，逐次记录该场科目构成、大题主题／论题、考点与教材章号映射，不逐题还原题干。
2. **可溯源题例汇编（题目级）**：以单场次为范围，收录**素材本身完整可核验**的题目，逐题标注来源与舍弃理由。
3. **考情证据台账（结构化登记）**：以结构化字段登记场次与题目级证据，作为本目录内证据的汇总登记。
4. **考情信源清单（来源字典）**：登记来源本身——信源、入口、级别、采集方式与采集使用规范，作为本目录全部文档来源标注的引用基准。

## 二、第一原则：不存在「官方真题」

**软考机考官方不公开试卷、不公布真题**。因此：

1. 本目录**不存在"官方真题"这一对象**，任何题目、题干、选项、答案均属**考生回忆或机构复盘**的产物；文档中禁止出现"官方真题""官方原题""官方答案"等表述。
2. 一切题目记录**必须同时标注来源与可信级**（见第四节），来源不可考者不入库。
3. 禁止 AI 生成、补全、扩写题目或选项；素材残缺的题目一律舍弃并列入舍弃清单，不得"合理推测"补齐。
4. 本目录文档**不作为考频统计的计数基数**——逐场实录记的是"主题与方向"，题目级汇编记的是"个案题例"，两者样本都不完整。

## 三、第二原则：只记事实，不产出考频结论

1. **禁止在本目录作出考频断言**：不得出现"高频""中频""低频""历年必考""近五年X次""考频★级"等分级表述；此类判断不属于本目录职责，本目录不作、也不指向。
2. **弃用分值锚定**：不写"上午X分""本章占X分"。分值来自培训机构估算而非官方，且随场次浮动；如确需交代分量，改用**题量（道）／频次（次）**表述，并注明口径。
3. **不得跨考试引用**：禁止以其他考试（尤其信息系统项目管理师"高项"）的考情替代系统分析师考情。
4. **场次命名规范**：统一写作"YYYY上／YYYY下"（如"2025下"）。系统分析师各场均系**单一批次**——官方批次安排通告中该资格恒列"第一批"，即其唯一批次（分批次实施的是报考人数较多的其他资格）；故记录单元即"场次"。如遇确有多批次的特例，须注明"批次"维度，统计单元不默认等于"场次"。

## 四、来源分级与可信级

**来源四级**（逐级递减，不可越级采信）：

| 级别 | 来源 | 用途 |
|---|---|---|
| L0 官方原点 | 考试大纲、官方教程、中国计算机技术职业资格网的考试计划／批次通告 | 定范围、定内容、定场次与版本启用时点 |
| L1 多源可核验回忆 | 考生一手回忆、机构复盘、回忆 PDF／文档 | 作可核验证据，须交叉印证 |
| L2 二手派生 | 机构真题解析书、网传"完整真题"、题库改编题 | 仅提供线索，不得作为记录来源直接入库 |
| L3 元信息 | 两版教材目录、省级人事考试网场次公告、合格线规则 | 用于核验与版本映射 |

**可信级标注（三档）**：

- **高**：L0 原文，或 L1 中经两个以上**相互独立**来源印证一致者；
- **中**：L1 单一来源但内部自洽、且与教材／考纲无冲突；
- **低**：来源单一且不可复核，或与其他来源存在冲突者——**低可信级条目只能列入候选池，不得进入正式记录**。

**交叉印证规则**：判定"独立"须排除同源复制（机构之间互抄、同一批次考生转述同一帖）。仅"两个以上来源一致"不足以保证独立，须能说明来源互不派生。

**冲突处理**：来源间不一致时，以官方教材／考纲原文为准，并在该条目备注冲突点；不得静默择一。

## 五、章节坐标与版本断层

1. **章节坐标唯一**：考点一律映射到《系统分析师教程（第2版）》的章号；考纲条目号可并列标注，但不作为主坐标。
2. **版本断层须标注**：2024版考试大纲与《系统分析师教程（第2版）》于2024年10月出版、**自2025年上半年起执行**。故：
   - 2021上～2024下各场为**旧大纲期**（按第1版教材命题）；
   - 2025上起为**新大纲期**（按第2版教材命题）。
   记录旧大纲期内容时，必须注明章号为"按第2版教材回溯映射"，不得使人误以为当年即按第2版章节命题。

## 六、头部声明（必填）

文档标题之后、正文之前，用引用块逐条列出，**至少包含四项**：

1. **适用科目**：综合知识／案例分析／论文，或跨科目的素材范围；
2. **场次范围**：覆盖的考试场次（列举"YYYY上／下"），缺录场次须显式说明；
3. **教材基准**：《系统分析师教程（第2版）》宋胜利，清华大学出版社；并声明章节坐标为回溯映射还是原生对应；
4. **来源与可信级**：主要来源级别（L0～L3）、可信级判定与舍弃规则。

可按需增补「文档定位」「题量口径」等行，但不得缺项。同目录内同类文档的头部要素须对齐。信源清单类文档仍用同一四槽，取值改为：适用科目＝跨科目；覆盖范围＝本目录引用的全部信源；教材基准＝不适用；来源与可信级＝本表即定义处。此外该类文档须含「登记规则」与「采集与使用规范」两节。
