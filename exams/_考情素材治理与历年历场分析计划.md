## 二、规范有效性确认（步骤 1）

### 2.1 结论

《考情信源清单与采集规范》**确认有效**，可同时承担两种角色：

1. **采集辅助文件**——它给出"证据从哪来、怎么取、怎么用、怎么标"的完整操作规范；
2. **采集范围边界标准**——它用登记规则、四级来源、八条规范划定了"什么可入库、什么只能作线索、什么必须排除"的边界。

### 2.2 支撑结论的规范构成

| 构成 | 位置 | 对采集的约束作用 |
|---|---|---|
| 登记规则（编号 `L{级别}-{两位序号}`） | 第一节 | 编号一经分配不复用；来源列引编号不抄链接 |
| L0 官方原点（唯一权威，可直接引用） | 第二节 | 定范围、定场次、定版本启用时点、定元信息（科目题型／合格标准／年度工作安排）；**不提供任何题目内容** |
| L1 多源可核验回忆（须交叉印证） | 第三节 | 含三因子加权评分规则（一手性 .40／覆盖度 .35／可回溯性 .25），按分降序、定主核与辅助 |
| L2 二手派生（仅线索，不入库） | 第四节 | 模拟题、改编题、"全网最全"默认降级 |
| L3 元信息（辅助核验） | 第五节 | **权威源优先**：元信息以 L0 为准，L3 仅对照转述、不得覆盖（2026-10-09 重写为三列） |
| 采集与使用规范（九条） | 第六节 | 采集即登记、警惕串场、独立印证、论文优先、题面解析分离、L2 降级、AI 边界、登记核验同步、**权威源优先** |
| 已知污染源与采信陷阱（7 实例） | 第七节 | 模拟题冒充实题、同主题跨科目混淆、题数不可信、机考时点、案例被论文顶替等 |
| 51CTO 逐场题数表 | 第八节 | 覆盖度交叉核验；**不得用于题量、频次跨场累计** |
| 逐场次页面登记（回填基准） | 第九节 | 编号 → 具体页面（标题＋URL）的对应；采集日期统一 2026-10-08 |

### 2.3 作为"边界标准"的三重含义

- **范围边界**：只收 **2021 年及以后**的系统分析师考情；**禁止引用其他资格**（尤其信息系统项目管理师"高项"）的考情；L2 不得直接入库；L3 仅作核验。
- **采信边界**：L0 为唯一权威；L1 必须交叉印证且能说明"互不派生"；单一来源仅"中"档；冲突者降"低"、只入候选池。
- **登记边界**：`信源编号＋页面标题＋URL＋采集日期` 四者**缺一不可**；且**登记与核验须同步**，仅登记未核验不得视为取得可采信性。

### 2.4 规范自身的边界与已知欠账（如实列出）

1. **第九节部分场次综合知识为"待批量提取"——✅ 已结项（2026-10-09）**：软题库（L1-03）登录态模考页收录的 8 场回忆版**已全部批量落库**（综合 8/8 场 464 题块；另案例 5 场 20 题块）。**⚠️ 但同源性核查显示 2021上～2025上 与 L1-01 逐字同源**，故"批量落库"≠"得独立第二源"，详见 §7.8。
2. **L1 内部质量不齐**——L1-01／L1-02 为"高"（可作主核），L1-03 为"高"但覆盖集中于 2025–2026，L1-04 有跨场串场前科、场次归属不可默认采信，L1-08／L1-09／L1-10 为"低"（仅线索）。
3. **规范未定义"计划/工作文档"的承载位置**——本文件即为该空白的临时处置（`_` 前缀），是否需要在 `exams/` 之外单设工作文档区，列入第六节决策点。

## 四、考情证据台账重构设计（步骤 3 之一）

### 4.1 目标

使台账与信源清单对齐、去除对旧文件的依赖，成为**信源清单驱动的唯一结构化证据登记表**。

### 4.2 保留

- 「场次总账」（场次／日期／形式·批次／大纲期／已收录证据／可信级／缺口）；
- 「考点级证据台账」（编号／场次／批次／科目／题号／考点／教材章节／大纲模块／来源／可信级／备注）；
- 「缺口清单」（下一批补录优先级）。

### 4.3 变更

1. **来源列一律引编号**（延续现行做法，全部指向信源清单第五节／第九节）；
2. **「说明」中指向旧文件的部分**——改为指向新建的场次轴／题面级载体，或在该载体未建前先标注"载体待建"；
3. **E-001～E-005**：待题面级新载体建立后改承新载体（不再承"汇编"）；
4. **「待复核项」并入台账**：如 2021上 试题四 场次归属、Cache 命中率跨场串场、L1-04 场次归属，集中登记一份「待复核清单」，避免散落各文档。

### 4.4 与信源清单的分工（不得混同）

- 信源清单＝**来源字典**（登记"来源本身"，含可信度评分）；
- 证据台账＝**证据登记**（登记"哪一场考了什么、据何来源"），其「高／中／低」为**证据复核档**（单源待复核＝中，取得第二独立来源复核通过后升档），与信源清单的来源可信级是**两套维度**。

## 五、历年历场考情分析计划（步骤 3 之二·本步交付物）

### 5.1 统一执行模板

每一场次按以下六段推进，产出物统一为**该场次三科（综合知识／案例分析／论文）的命题方向与考点分布记录**（落于新的场次轴载体，符合信源清单与 exams/SKILL.md）。

1. **证据底座**：该场现有可入库证据、来源编号、覆盖度；
2. **缺口与风险**：缺录题、待复核项、串场／模拟题污染提示；
3. **采集动作**：下一步要取的来源（编号＋入口），含软题库 L1-03 批量提取；
4. **核验动作**：取得第二家**相互独立**来源、逐题比对、串场回溯；
5. **分析产出**：三科命题方向／考点分布（只记事实，不作考频分级）；
6. **完成判据 ＋ 依赖**：达到何种状态视为该场完成，前置条件是什么。
